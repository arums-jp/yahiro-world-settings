# 小説設定：中継拠点の物語

**タイトル**：辺境拠点日誌　〜三集落の中間でのんびり（？）野廻り〜

────────────────────────────────────────

## 0. 作品の基本方針

- **ジャンル**：ライトノベル（ギャグ・お笑いネタも含むお気軽な作風）
- **全体構成**：第1部で30話、1話あたり約4,000文字
- **避けるもの**：ハーレム展開・主人公無双展開
- **描きたいもの**：世界に根付いた地道な活動の積み重ねによる信頼・影響力の拡大
- **戦闘要素**：脅威となる獣に対しては派手な戦闘シーンも入れる

### 「野廻り」という呼称について

主人公たちが自分たちの仕事につけた通称。正式名称は「集落周辺哨戒業従事者」という堅苦しい名称だが、誰も使っていない。

────────────────────────────────────────

## 1. 物語の背景

### 発端

集落が安全圏を維持できていた頃は不要なシステムだったが、自然界の獣が脅威となり始めたため、最寄りの集落同士が連携をとる必要が生じた。その取り決めの結果として、3つの集落の中間地点に集落間移動の中継所兼周辺の獣の監視所を新たに作ることになった。

### 拠点の概要

- **位置**：3つの集落の中間地点
- **目的**：集落間移動の中継・周辺の獣の監視・緊急時の救援連絡
- **設立経緯**：3集落の合意による共同設立
- **初期人員**：3集落からそれぞれ約10人、計30人程度が建設に参加
- **常駐人員**：建設後は10数人が常駐
- **初期資材輸送**：各集落は大量の建設資材・食料を自力で運ぶ手段を持たないため、移動中の隊商に依頼して拠点予定地まで荷を輸送してもらった。荷を下ろした隊商はそのまま次の集落へ向かった。
- **継続的な物資補給**：以後の物資補給も隊商の来訪に合わせて依頼する形をとる。隊商が来るまでの間は現地調達と節約で凌ぐ。隊商の来訪日程は固定されていないため、「次の物資がいつ届くか」は常に拠点の懸案となる。

### 拠点の成長

- 最初は最低限の小屋のみの状態からスタート
- 少しずつ豊かにしていき、常駐者が増えていく
- 最終的に3集落と友好的な関係を持つ独立した集落となる
- 立地上、隊商の交易路の中継所としても機能するようになる

────────────────────────────────────────

## 2. 主要人物：野廻り隊5人

拠点を中心に周囲を巡回する5人が物語の中心。危険な獣の監視・排除・偵察が主な役割。（正式名称：集落周辺哨戒業従事者）

### 構成

| 役割 | 特徴 |
|-----|-----|
| 罠師 | 罠の設置・管理に長けている |
| 弓師 | 弓術に長けた遠距離戦闘担当 |
| 薬師 | 植物・薬学に長けており野外での医療も担う |
| 斥候 | 身軽で偵察・情報収集が得意 |
| 主人公 | 特異な能力を持つ（後述） |

### 物語上の機能

- 冒険者パーティ的な少人数チームとして機能
- 拠点が安定・成長するにつれて行動範囲が広がる
- 隊商の護衛として同行し、拠点の外の舞台にも展開できる

────────────────────────────────────────

警邏隊5人以外の常駐者：

- **資源管理担当**

## 4. 主人公の設定

### 能力

**古代の知識の読解・理解**：古代文字や失われた高度技術に関する知識の断片を持つ。遺跡・古代システムと接触するほど価値が増す能力。

### 出自と背景

**家系**：語り部の血縁。一族は古代の言語だけでなく高度な技術にも届く知識を代々保持していた。すべてを語ることは危険だと判断した一族は、真実を伝承しつつも何を公開するかを厳格にコントロールしていた。

**幼少期**：病弱でよく寝込んでいた。語り部であった父親は主人公がこのままでは成人まで生きられないことを悟り、禁域から「ナノマシン」を持ち帰って主人公に投与した。

**父親の死**：投与から数年後、父親は事故で死亡。何を知っていたか・何をしたかを完全に語らないまま逝った。

**成人後**：語り部の職は引き継がなかった。しかし生前の父親からかなりの知識を受け取っている。成人のタイミングで中継拠点設立メンバーとして志願した。

### 主人公の多層的な特殊性

| 層 | 内容 | 周囲への開示度 |
|----|-----|------------|
| 知識 | 古代文字・失われた技術の断片的な理解 | 部分的に開示可能 |
| 身体 | ナノマシン投与による何らかの底上げ | 本人も詳細を知らない |
| 出自 | 禁断の知識を管理してきた一族の末裔 | ほぼ非開示 |

### 未解決の謎（物語の伏線）

- 父親がなぜナノマシンを禁域から持ち出せたのか
- 父親の「事故死」は本当に事故だったのか
- ナノマシンが主人公の身体・能力に与えた影響の全貌
- 一族が「危険だ」と判断して秘匿してきた知識の内容

## 5. 物語の構造（仮）

### 第一部：建設と定着

- 拠点を作る苦労
- 3集落から来た人間の摩擦と融合
- 警邏5人が周囲の地形・獣・危険を把握していく

### 第二部：独立集落への成長

- 拠点が機能し始め、元の3集落との関係が「親子」から「対等」に変化
- 個人の選択（故郷に帰る者、完全に定住を決める者）

### 第三部以降：外の世界へ

- 隊商の護衛として5人が同行し、拠点の外へ
- 遺跡・古代技術との接触で主人公の知識・身体の謎が少しずつ開示される

### 拠点の成長と行動範囲の連動

拠点が安定するほど5人が遠くに行けるようになる。拠点の成長と主人公たちの行動範囲の拡大が物語の進行と連動する。

## 8. 地図と地理知識の設定

### この世界に正確な地図はない

各集落が持つのは「集落を中心とした略図」のみ。方位（北・南・東・西）と「歩いて何日か」の距離感が示されているが、精度は低い。作成者が実際に行ったことのない場所は空白か推測で埋まっており、集落から遠ざかるほど不正確になる。

測量技術・高所からの俯瞰手段がないため、全域の正確な地図は誰も持っていない。地図師という職業は存在するが、希少職のため小さな集落にはまずいない。

### 物語への活かし方

| 場面 | 活かし方 |
|-----|---------|
| 集落間の中間地点選び | 三集落の略図はそれぞれ「このあたりが中間」という程度。来てみて初めてわかる |
| 危険生物の出没 | 略図には載っていない。知らなくて当然 |
| 旅人が道に迷う | 略図にない迂回路で迷う。口伝の知識がなければ動けない |
| 野廻り隊の危険マップ | この世界ではきわめて価値のある作業。地域の実態を地図化する人間がほぼいない |
| 中継拠点の価値 | 旅人・隊商が情報を持ち込み、拠点が地理知識の蓄積場所になる |

### 禁止事項

- 住民が精確な地図を持っている描写
- 「地図を見ながら」という描写（略図を持っている場合は「大まかな略図」と表現）

### 標塔と地図の関係

地図の代わりに標塔が方向基準として機能している。「あの標塔の方向に進む」「標塔を左に見ながら」という表現が旅人・隊商の日常語。略図にも標塔の位置だけは必ず記されている。

## 9. 標塔の登場方針

### 基本方針

標塔（ひょうとう）は**第1部を通じて頻繁に登場させる**。初期状態からSFを感じさせる最重要要素。住民にとっては完全に日常的な存在として描き、SF的な異質感はセリフや説明ではなく、描写の中から滲み出るようにする。

読者だけが「おかしい」と気づく。キャラクターは誰も疑問に思わない。

### 登場のさせ方

| 種類 | 例 | 効果 |
|-----|----|----|
| 方向の目印 | 「標塔の方向を基準に」「標塔の手前の道」 | 住民が日常的に使っている事実を示す |
| 景色の一部 | 「北の標塔が光っていた」「いつもの標塔の線」 | 当たり前の風景として自然に溶け込む |
| 動じない描写 | 嵐の中でもまっすぐに立っている | 読者だけが違和感を覚える（最重要） |
| 素材の一致 | 石積みと同じ光沢 | 古代遺物とのつながりをカイが連想する |

### 禁止事項

- キャラクターが「標塔とは何か？」と疑問を口にしない
- 地の文に説明的な記述（「標塔はMTM制御ノードであり……」等）を入れない
- 初登場時に注釈・補足説明を入れない

### 三ツ辻から見える標塔

拠点（標高約80m）からは2本の標塔が視認可能（詳細は `拠点と周辺地理.md` 参照）：

- **北の標塔**（カネヅカ方向・北北西・約37km）：最も見やすい。丘の稜線を越えて上部が見える。日常的な方向確認の基準として住民が使う。
- **南東の標塔**（ミナシロ方向・南東・約40km）：晴れた日に視認可能。川岸（ナル川）に出ると視界が開けてよく見える。ミナシロからの旅人も目印として使う。

### 第1部での登場実績（既存話への追記分）

| 話数 | 登場箇所 | 種類 |
|-----|---------|-----|
| 第1話 | カイが場所を選ぶ場面・北の稜線 | 景色の一部 |
| 第2話 | 柵の向きをそろえる場面 | 方向の目印 |
| 第3話 | 翌朝晴れた場面 | 景色の一部 |
| 第4話 | 川へ向かう道から | 景色の一部 |
| 第5話 | 採集班が外に出た場面 | 景色の一部 |
| 第6話 | ヤエが来る方向の描写 | 方向の目印 |
| 第7話 | 嵐の場面（最重要） | 動じない描写 |
| 第8話 | 石積みを見る場面 | 素材の一致 |

## 10. 集落外移動と隊商依存

### 基本原則

集落の住民は基本的に集落の安全圏の中で生涯を過ごす。安全圏の外への移動は隊商とともに行うのが通例。単独での集落外移動は「危険な行為」として認識されている。

### 移動の実態

| 状況 | 方法 |
|-----|-----|
| 荷物の輸送 | 隊商に依頼。集落には荷馬車がほとんどない |
| 人の移動（集落→集落、集落→拠点） | 目的地が同方向の隊商とともに移動。来るまで待つか、交渉して目的地を変えてもらう |
| 少人数の急ぎの移動 | 護衛を雇うか、危険を承知で単独移動（旅人遭難の主な原因） |
| 拠点→集落の連絡 | 隊商の来訪に便乗するか、特別に使者を出す |

### 物語での活かし方

- 「隊商が来なければ孤立する」という拠点の基本的な制約として機能
- 三ツ辻拠点が隊商の中継地になることで、この制約から徐々に解放される（成長の動線）
- 旅人の遭難・助けの場面で「なぜ単独で旅していたか」の説明に使える
- 集落の代表者が拠点を訪れる際も隊商の来訪に合わせて来ることが多い
- 3集落から30人が集まった「三ツ辻の設立自体」が、隊商協力なしには実現しなかった

### 禁止事項

- 集落の人間が何の段取りもなく単独で集落間を移動している描写
- 拠点から集落への連絡が容易な描写（実際は隊商の来訪を待つか急使を出すしかない）
