# 執筆方針：会話トーンと関係性の変化

## 基本方針

野廻り隊のメンバー（カイ・ガン・ミコト・リュウ・スズ）および拠点常駐メンバー（ドウ・ハナ・クワ・セリ・ケン）の会話は、話数が進むにつれて「他人どうし」から「家族に近い空気」へと変化する。

**いじめではなく、いじり**。相手のことをよく知っているからこそできるからかいであること。どのやり取りも愛情の表現として書く。

---

## 第1部の章ごとのトーンの目安

### 第1章（1〜8話）：ぎこちない他人
- 全員が敬語ベース
- 笑いはあっても「いじり」「からかい」はない
- スズが最初にほぐれ始める（4話から）

### 第2章（9〜16話）：距離が縮まりつつある
- 野廻り隊5人の間でスズ主導のいじりが始まる
- ガンは「うるさい」「ほっとけ」と言いながら最終的に受け入れる
- リュウへの「また試してる」定番いじりが登場
- カイは天然ボケとして機能する
- 拠点常駐も気安くなっている

### 第3章（17〜23話）：仲間として確立
- 危機の最中でも一言二言のいじりが入る
- ガンがスズをからかうことも出てくる（関係が対等に）
- ミコトの返しが少し増える

### 第4章（24〜30話）：家族に近い空気
- 野廻り隊5人は友人間のノリ
- 拠点全体に大きな家族のような空気
- ケン退場（29話）の重さをいつも通りの会話トーンが支える
- これ以降はとても親しい仲間としての会話になる

## キャラクター別いじり・からかいのパターン

### スズ → ガン
「ガンさんって〜ですよね」「褒められましたね」「嬉しそうです」
→ ガンが素直に喜んでいる／照れているのを外から実況する形。
→ ガンは「うるさい」「ほっとけ」と返すが止めない。

### スズ → リュウ
「また一人で試しましたね」「記録する顔してます」
→ 応援に近いいじり。リュウの暴走を楽しんでいる。

### ガン → スズ（第3章以降）
「お前それで大丈夫なのか」「どこから出てきた発想だ」
→ 呆れつつ認めている口調。

### カイ（被いじられ）
天然なことを言う → スズかガンに「カイさんはそういうことを言う人ですよね」
→ カイは「そうですか」で受け流す。定番のやり取り。

### リュウ → 全員
興奮すると話が止まらなくなる → 全員「一回落ち着いて」「三行で」

### ミコト（被いじられ）
感情が薄い発言 → 「ロマンがないですね」→「違います」
→ 徐々にミコトの返しが一言増えていく。

### ハナ → 野廻り隊
「何かまた変なものを見つけてきましたか」（大抵当たっている）

### クワ → 野廻り隊
「また何か壊しましたか」→「壊していません」→「今回は？」

## 書き方の注意点

- **敬語を一律に消さない**：スズはもともと丁寧語の人物。「〜ですよね？」「〜じゃないですか」という敬語ベースのいじりが自然。
- **ガンは怒鳴り口調が基本**：仲良くなっても声は大きい。大声で「うるさい！」と言いながら笑っている状態が理想。
- **ミコトは変えすぎない**：口数が増えると別人になる。「あと一言だけ追加する」程度の変化で十分。
- **からかいは愛情の表現**：いじめではなく「この人のことをよく知っているからできる」という前提。
- **緊張場面での一言**：危機の最中の軽いやり取りは削らない。読者がほっとできる呼吸になる。
- **ノリツッコミの呼吸**：スズがボケを仕掛けてガンがツッコむ、または全員が乗っかる、という2パターンを使い分ける。

## 読者視点での会話補足

登場人物どうしなら省略して通じる会話でも、読者視点では「誰が・何を・どこで」が伝わりにくい場面がある。会話だけで状況が浮かぶよう、以下の二つを意識する。

### 1. 会話の中に「対象」「場面」を自然に織り込む

- **悪い例**：「着きましたね」「着きましたね」
- **良い例**：「四日も歩いて、ようやく着きましたね」「着きましたね。ハラダを出てから、もう何度野営したか」

会話を発する人物が、その場の状況・経緯・距離感を自然に口にすることで、読者にも「いま何が起きているか」が伝わる。ただし**説明セリフにはしない**——あくまで「その人物がその場で言いそうなこと」の範囲で補う。

### 2. 会話と会話のあいだに、短い状況描写を挟む

連続する会話の合間に、一文〜二文で「誰がどう動いたか」「視線・表情・場の空気」を描く。

- **悪い例**：
    「南東の平地がいい」
    「北西の丘のほうがいい」
    「南西の森の縁が近いほうが」

- **良い例**：
    「南東の平地がいい」とタケオが腕を組んだまま言った。地面に視線を落としたまま、迷う様子もない。
    ミコトはタケオの言葉を最後まで聞いてから、ゆっくり首を動かした。「北西の丘のほうがいい」
    スズが、二人の顔を交互に見比べてから口を開いた。「南西の森の縁が近いほうが、薬草の採集に便利では」

### 3. 補足の量の目安

- 会話一つあたり、補足は**最大でも一文程度**。長くなると地の文の役割を奪う。
- 会話三〜四往復に一回は、状況描写を一文挟む。
- 緊張場面（戦闘・決断）では補足を減らし、テンポを優先する。
- 日常場面（食事・夜の会話）では補足を多めに入れて、読者をその場に置く。

### 4. 既存のキャラ口調・関係性は崩さない

- ガンの「うるさい」「ほっとけ」のような短い返しは**短いまま残す**。長くしない。
- スズの「〜ですよね？」のいじりは、補足なしでも成立するため過剰に説明しない。
- カイの天然発言は、説明しすぎると「天然」が消える。受け手側のリアクションで状況を伝える。

## 会話タグの多様化（単調さを避ける）

会話文が「〜と○○が言った。」「〜と○○が聞いた。」で終わる形で続くと、リズムはあっても淡々と平板に聞こえる。発話者を示す方法を意図的に散らし、めりはりをつける。

### 問題の例（タグが行末に規則的に並ぶ）

```
「では試します」とリュウが当然のように言った。
「お前が試すのは別の意味で危ない」とガンが言った。
「なぜですか」とリュウが本当にわかっていない顔で聞いた。
```

→ 「言った／聞いた」が三連続し、文の骨格が同じで単調になる。

### 改善後の例（省略・動作・語順を混ぜる）

```
「では試します」とリュウが当然のように言った。
　ガンが手元から目を上げた。「お前が試すのは、別の意味で危ない」
「なぜですか」
　本当にわかっていない顔だった。
```

### 発話者の示し方（これらを混ぜる）

1. **タグを省略する**：往復が続いて発話者が明らかなら、「と○○が言った」を消してセリフだけにする。二人の会話なら特に有効。
2. **動作・情景ビートに置き換える**：「言った」の代わりに、その人物の動作・視線・手の動きで発話者を示す。「ガンが顔を上げた。『〜』」「スズが鎌の柄を握り直した。『〜』」
3. **語順を変える**：タグを文頭・文中に置き、行末への集中を崩す。「リュウは聞き返した。『なぜですか』」
4. **間・反応で受ける**：発話動詞を使わず、次の一文で相手の反応や表情を描いて受ける。「『なぜですか』／本当にわかっていない顔だった。」
5. **発話動詞に変化をつける**：どうしても「言った」を使う時も、場面に応じて「返した／続けた／切り出した／つぶやいた／遮った」等を織り交ぜる（ただし乱用しない。「叫んだ」「囁いた」等の強い動詞は本当に必要な時だけ）。

### 使い分けの目安

- **同じ話者を示す動詞（言った/聞いた/返した）は、3回以上連続させない**。2回続いたら、3つ目は省略か動作ビートに変える。
- **テンポの速い掛け合い**（いじり合い・緊張場面）ではタグ省略を多めに。地の文を挟みすぎると会話の速度が死ぬ。
- **しんみりした場面・重要な発言**では動作ビートや間で受けて、ゆっくりした呼吸を作る。
- **地の文過多に注意**：ビートを入れすぎると今度は会話が重くなる。「タグを消す」と「動作を足す」のバランスで、地の文の総量はむしろ増やしすぎない。
- ガンの短い返し（「うるさい」等）は、タグごと省略しても成立することが多い。積極的に省く。

## 日本語らしさ（humanizer-ja スキル準拠）

`~/.claude/skills/humanizer-ja` の原則のうち、**小説の地の文・会話に効くもの**を採用する。実用文・エッセイ向けの項目（数字への置換・自分の体験や意見の挿入・出典明示など）は小説では使わない。

### 1. 語尾・文体を均一にしない

「言った。」「〜だった。」など同じ語尾が続くと平板になる。断定・体言止め・問いかけ・短文を混ぜて、リズムに緩急をつける。長い文の後に短い一文を置く。

### 2. 主語を省く

日本語は主語を省く言語。「リュウが」「ガンが」「カイが」を毎文入れない。文脈で分かる主語は落とす。会話の往復では、動作の主だけ示せば発話者は伝わる。

### 3. 全角ダッシュ（——）を多用しない

補足や余韻に「——」を使いすぎると、いかにもな書き癖になる。読点・句点・カッコ・改行で代替できる箇所は置き換える。本当に効かせたい一箇所だけに絞る（章の締めの余韻など）。

### 4. 「〜することができる」を短縮

「動かすことができる」→「動かせる」。「読むことができない」→「読めない」。冗長な可能表現は縮める。

### 5. 説明の付け足しを削る

事実・描写の後に「〜ということを示している」「〜を物語っていた」と意味を説明で足さない。描写だけ置いて、解釈は読者に委ねる。地の文で状況を"説明"しすぎず、"見せる"。

### セルフチェック（推敲後に問う）

書き直したら「これは淡々と起きたことを並べただけになっていないか」「同じ語尾が三つ続いていないか」「主語が毎文入っていないか」を確認する。該当したらもう一度直す。
