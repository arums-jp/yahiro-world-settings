# 執筆方針：会話トーンと関係性の変化

## 基本方針

野廻り隊のメンバー（カイ・ガン・ミコト・リュウ・スズ）および拠点常駐メンバー（ドウ・ハナ・クワ・セリ・ケン）の会話は、話数が進むにつれて「他人どうし」から「家族に近い空気」へと変化する。

**いじめではなく、いじり**。相手のことをよく知っているからこそできるからかいであること。どのやり取りも愛情の表現として書く。

---

## 第1部の章ごとのトーンの目安

### 第1章（1〜8話）：ぎこちない他人
- 全員が敬語ベース
- 笑いはあっても「いじり」「からかい」はない
- スズが最初にほぐれ始める（4話から）

### 第2章（9〜16話）：距離が縮まりつつある
- 野廻り隊5人の間でスズ主導のいじりが始まる
- ガンは「うるさい」「ほっとけ」と言いながら最終的に受け入れる
- リュウへの「また試してる」定番いじりが登場
- カイは天然ボケとして機能する
- 拠点常駐も気安くなっている

### 第3章（17〜23話）：仲間として確立
- 危機の最中でも一言二言のいじりが入る
- ガンがスズをからかうことも出てくる（関係が対等に）
- ミコトの返しが少し増える

### 第4章（24〜30話）：家族に近い空気
- 野廻り隊5人は友人間のノリ
- 拠点全体に大きな家族のような空気
- ケン退場（29話）の重さをいつも通りの会話トーンが支える
- これ以降はとても親しい仲間としての会話になる

## キャラクター別いじり・からかいのパターン

### スズ → ガン
「ガンさんって〜ですよね」「褒められましたね」「嬉しそうです」
→ ガンが素直に喜んでいる／照れているのを外から実況する形。
→ ガンは「うるさい」「ほっとけ」と返すが止めない。

### スズ → リュウ
「また一人で試しましたね」「記録する顔してます」
→ 応援に近いいじり。リュウの暴走を楽しんでいる。

### ガン → スズ（第3章以降）
「お前それで大丈夫なのか」「どこから出てきた発想だ」
→ 呆れつつ認めている口調。

### カイ（被いじられ）
天然なことを言う → スズかガンに「カイさんはそういうことを言う人ですよね」
→ カイは「そうですか」で受け流す。定番のやり取り。

### リュウ → 全員
興奮すると話が止まらなくなる → 全員「一回落ち着いて」「三行で」

### ミコト（被いじられ）
感情が薄い発言 → 「ロマンがないですね」→「違います」
→ 徐々にミコトの返しが一言増えていく。

### ハナ → 野廻り隊
「何かまた変なものを見つけてきましたか」（大抵当たっている）

### クワ → 野廻り隊
「また何か壊しましたか」→「壊していません」→「今回は？」

## 書き方の注意点

- **敬語を一律に消さない**：スズはもともと丁寧語の人物。「〜ですよね？」「〜じゃないですか」という敬語ベースのいじりが自然。
- **ガンは怒鳴り口調が基本**：仲良くなっても声は大きい。大声で「うるさい！」と言いながら笑っている状態が理想。
- **ミコトは変えすぎない**：口数が増えると別人になる。「あと一言だけ追加する」程度の変化で十分。
- **からかいは愛情の表現**：いじめではなく「この人のことをよく知っているからできる」という前提。
- **緊張場面での一言**：危機の最中の軽いやり取りは削らない。読者がほっとできる呼吸になる。
- **ノリツッコミの呼吸**：スズがボケを仕掛けてガンがツッコむ、または全員が乗っかる、という2パターンを使い分ける。

## 読者視点での会話補足

登場人物どうしなら省略して通じる会話でも、読者視点では「誰が・何を・どこで」が伝わりにくい場面がある。会話だけで状況が浮かぶよう、以下の二つを意識する。

### 1. 会話の中に「対象」「場面」を自然に織り込む

- **悪い例**：「着きましたね」「着きましたね」
- **良い例**：「四日も歩いて、ようやく着きましたね」「着きましたね。ハラダを出てから、もう何度野営したか」

会話を発する人物が、その場の状況・経緯・距離感を自然に口にすることで、読者にも「いま何が起きているか」が伝わる。ただし**説明セリフにはしない**——あくまで「その人物がその場で言いそうなこと」の範囲で補う。

### 2. 会話と会話のあいだに、短い状況描写を挟む

連続する会話の合間に、一文〜二文で「誰がどう動いたか」「視線・表情・場の空気」を描く。

- **悪い例**：
    「南東の平地がいい」
    「北西の丘のほうがいい」
    「南西の森の縁が近いほうが」

- **良い例**：
    「南東の平地がいい」とタケオが腕を組んだまま言った。地面に視線を落としたまま、迷う様子もない。
    ミコトはタケオの言葉を最後まで聞いてから、ゆっくり首を動かした。「北西の丘のほうがいい」
    スズが、二人の顔を交互に見比べてから口を開いた。「南西の森の縁が近いほうが、薬草の採集に便利では」

### 3. 補足の量の目安

- 会話一つあたり、補足は**最大でも一文程度**。長くなると地の文の役割を奪う。
- 会話三〜四往復に一回は、状況描写を一文挟む。
- 緊張場面（戦闘・決断）では補足を減らし、テンポを優先する。
- 日常場面（食事・夜の会話）では補足を多めに入れて、読者をその場に置く。

### 4. 既存のキャラ口調・関係性は崩さない

- ガンの「うるさい」「ほっとけ」のような短い返しは**短いまま残す**。長くしない。
- スズの「〜ですよね？」のいじりは、補足なしでも成立するため過剰に説明しない。
- カイの天然発言は、説明しすぎると「天然」が消える。受け手側のリアクションで状況を伝える。
