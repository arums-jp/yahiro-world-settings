# 登場人物設定（第3部用）

第2部からの引き継ぎと、第3部から登場する新メンバーをまとめる。
既存キャラクターの状態は `登場人物_第2部.md` を参照すること。

**時間軸**：拠点設立3年目の春〜4年目の春

────────────────────────────────────────

## 話数とプロットのずれについて（重要）

第3部プロットでは第71話を「扉を開ける」としているが、実際に執筆された第71話は
「三年目の春、扉の前へ」で終わっている（扉はまだ開いておらず、鍵が必要という引き）。

そのため**実際の話数 = プロットの話数 + 1**でずれている。
- プロット第71話「扉を開ける」 → 実話数 第72話
- プロット第110話「三ツ辻、外への入口になる」 → 実話数 第111話

執筆時は実話数で進め、プロットの該当話を +1 して参照すること。

## 野廻り隊5人（第3部時点の変化）

### 1. カイ（主人公）
**年齢**：22〜23歳（第3部中）
- 禁域の管理者認証に反応する体。だが「鍵」になることへの戸惑いを抱える。
- 父カツオが禁域から医療技術（ナノマシン）を持ち出して自分を救った事実に、段階的に近づく。
- 「鍵にはなるが、一人では進めない」——仲間と一緒に扉を開けることが第3部の核。
- 一人称は「私」。「みんなで」が定着。父の行動を「言葉ではなく行動で読む」内省が増える。

### 2. ガン（罠師）
**年齢**：26〜27歳。
- クロに罠と見張りの一部を任せる立場。口を出しすぎて逆に邪魔になるコメディ。
- 足の古傷が残り、無理な行軍はできない。「冷たい地面が嫌い」。
- カツオの選択を「誰かを守るための判断」として責められない、静かな共感を持つ。
- 一人称「俺」。怒鳴りは健在だが「……そうか」の納得の間が増える。

### 3. ミコト（弓師）
**年齢**：24〜25歳。
- 広域地図・測量の中核。スズの直感的な道覚えと両立させる必要が出る。
- カネヅカ時代にウロジカ（希少騎乗獣）を扱った過去がある（第3部で明かす）。
- 一人称「私」。「記録する」が口癖。ロマン側へ少しずつ歩み寄る。

### 4. リュウ（薬師）
**年齢**：23〜24歳。
- 禁域資料で暴走しがち。アサが記録・荷物を整理して止める逆転関係。
- ツキとの協働で「試す前に考える」が少しだけ身についた。
- 一人称「僕」（目上・改まった場では「私」）。「記録します！」健在。

### 5. スズ（斥候）
**年齢**：21〜22歳。
- 地図の外で本領発揮。失敗を経て「ここまでにします」と自分で止まれる。
- ミルクの子バターの命名者。第3部ではウロジカの子ウメ・マツも命名する。
- 一人称「私」。丁寧語ベースのいじりが持ち味。

## 拠点常駐メンバー（第3部）

- **ドウ**（全体管理者・帳簿）：情報に値段と責任があると考え始める。禁域情報の公開範囲を管理。一人称「私」。
- **ハナ**（調理）：禁域探索用の携行食・帰還食を作る。「食べて帰る」が信条。目覚めた者への最初の接触も食事。一人称「私」。
- **クワ**（資源・建設）：マタと組んで厩舎・資料室・宿泊棟を増築。一人称「私」。
- **セリ**（医療）：カイの体調記録を日課化。アオイの医療判断も担う。一人称「私」。
- **アサ**（採集補助→記録補助）：リュウの暴走を整理で止める役へ。資料室の管理役として定着。一人称「私」。返事が一拍遅れる。
- **マタ**（建設）：クワと無言で連携。少しずつ言葉が増える。一人称「私」。
- **クロ**（ガンの弟子）：罠と見張りを任され、拠点側の防衛で役割を確立。一人称未確定（「自分」を使う）。
- **ミルク・バター**（除草係の白い獣・親子）：通奏低音。バターは好奇心旺盛で禁域道・隊商荷物に近づいては止められる。

## 第3部からの新登場人物

### アオイ（保存槽で眠っていた旧時代の人物）
**登場**：第106話（実話数）〜
- 外部記録担当。「外を知る者」。透明な蓋の保存槽で二千年眠っていた。
- 古代の衣服。カイの古代文字理解と施設の補助表示で断片的に意思疎通。
- 最初の問い「ここは、ヤヒロですか」「航行は、まだ続いていますか」。
- 「ヤヒロ」を伝承ではなく古代側の正式呼称として口にする初の人物。
- すべては語らない（語れない）。第4部への扉となる存在。

### クズハ（ウロジカの調教師）
**年齢**：40代。**出身**：カネヅカ。**登場**：第82話相当〜
- ミコトの旧知。馬具一式を持って来訪し、厩舎管理人として三ツ辻に定着。
- ウロジカを見て「生きていたのか」と言う。希少種の知識を持つ。
- 寡黙だが要点を押さえる。隊商の馬も預かれるようにし、宿泊機能を拡充。

### 外部市の道守り
**登場**：第91話相当
- 三集落外の小集落の野廻り相当職。行動範囲は集落周辺に限られる。
- 三ツ辻の野廻り隊が隊商と何日も移動することに驚く。三ツ辻の特殊性を映す比較対象。

### 銀縄隊の若手人員
**登場**：第88話相当〜
- サリム隊商の補助役。隊商側の日常と、外から見た三ツ辻評価を語る役。

## 第3部の新要素：ウロジカ（騎乗獣）

- 鱗状の体毛と鹿のような角を持つ四足獣。希少種で、カネヅカでも数十年目撃情報がなかった。
- 第82話相当で母を鎌爪竜の傷で看取り、子二頭（雌・ウメとマツ）を保護・養育する。
- 三年ほどかけて調教し、騎乗できるようになる。長距離の隊商護衛で活躍。
- ミルク・バター（除草係）とは別系統。厩舎で管理する。
