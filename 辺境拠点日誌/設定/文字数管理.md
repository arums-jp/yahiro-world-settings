## 計測方法について

### 採用する計測方法

**Python による文字数カウント**を標準とする。

```python
import re, os

path = 'ファイルパス'
text = open(path, encoding='utf-8').read()
# 見出し・区切り線・空行を除いた本文行を結合
lines = [l for l in text.splitlines() if l and not l.startswith('#') and not l.startswith('---')]
body = '\n'.join(lines)
# 改行を除いた文字数（全角スペースは文章の一部として含む）
count = len(re.sub(r'\n', '', body))
```

除外するもの：
- `#` で始まる見出し行
- `---` の区切り線
- 空行
- 改行文字

### wc -m が誤った理由

当初使用した `wc -m` はこの環境（Windows上のbash）では**バイト数**を返していた。日本語の全角文字はUTF-8で3バイトのため、実際の文字数の約3倍の値が出ていた（例：2,690字 → 8,136と表示）。

### 目標文字数について

プロットでは「1話あたり約4,000文字」を想定。第1部・第2部ともに平均3,000〜3,500字程度で推移している。

## 備考

- 文字数の計測はPythonスクリプトで行う（`wc -m` は日本語で誤カウントするため使用しない）
- 文字数表記は各話ファイル内には記載しない（このファイルで一元管理）
- 新しい話を執筆したら、このファイルの表に追記すること
