# 衣服と装備

────────────────────────────────────────

## 基本スタイル

ヤヒロの住民の日常着は、日本の伝統的な作業着をベースにしている。

**基本の衣形**：
- **作務衣**（さむえ）：上下セパレート。上着の袖は作業時に紐で縛る。最も広く使われる。
- **甚平**（じんべい）：暑い季節・屋内用。袖が短く涼しい。
- **茶衣着**（ちゃぎぬ）：ゆったりした上着。医療・薬師など、細かい作業をする者が好む。
- **割烹**（かっぽう）着：エプロン状の上掛け。調理・食品加工の際に着用。

**共通の特徴**：
- 動きやすさを最優先。余裕のある大きさで作る。
- 必要に応じて紐で縛って調整する（袖・裾・腰など）。
- 素材は亜麻・苧麻・大麻などの植物繊維が主流。上質なものは草絹（この世界固有の素材）や羊毛。
- 色は無染色（生成り・白系）か、植物染料による渋い色（茶・藍・柿・草色など）。
- 補修を繰り返して長く使う。破れた部分に別布を当てる「繕い」が当然の文化。

## 職能別のカスタマイズ

### 野廻り（斥候・狩猟・巡回）

基本の作務衣に以下を加える：

- **脚絆**（きゃはん）：膝下から足首を覆う。捕縛蔦・棘・湿地での浸水を防ぐ。植物繊維の厚布か骨甲薄板を縫い込んだもの。
- **手甲**（てっこう）：手の甲から前腕を覆う。骨甲の薄板を縫い込んだ強化版が野廻り用。
- **腰帯に小物入れ**：薬草・嫌音鈴・ナイフを吊るす。
- **袖は常に縛る**：木や獣に引っかかることを避けるため。
- **暗色の生地**：夜間・森中で目立たないよう、茶・墨・藍染めを好む。

**カイ（主人公）**：標準的な野廻りスタイル。目立たない墨色の作務衣。物入れを複数持ち歩く癖がある（父親のメモや道具類）。

**ガン（罠師）**：厚手の作務衣。袖と裾を短く切り詰めている（罠の蔓縄が引っかかるのを嫌う）。腰に工具入れを多数下げている。

**ミコト（弓師）**：右腕の袖だけを取り外せる作りにしている（弦への干渉を防ぐ）。弓の弦が当たる左前腕に骨甲の当て革。

**リュウ（薬師）**：茶衣着スタイル。ポケット・袋が異常に多い（薬草・道具・ノートを大量に入れる）。肌に染料のシミが絶えない。

**スズ（斥候）**：全員の中で最も軽装。生地も薄く、動きを最優先。甚平ベースに脚絆と手甲だけ追加。

### 建設・大工・鉱山

- 厚手の作務衣。膝に骨甲の当て当てをつける。
- 頭に布を巻く（埃よけ・汗止め）。
- 腰に工具入れ。

**クワ**：汚れを気にしない厚手の作務衣。常に腰に骨甲製の工具入れを下げている。

**イサ（井戸掘り）**：全身が土で汚れることを前提にした、最も粗末な作務衣。脚絆は骨甲板入りで坑道の岩肌から膝を守る。

### 調理・食品管理

- 割烹着を常に着用。
- 袖は常に縛るか折り返す。
- 腰に布巾を複数下げる。

**ハナ**：明るめの色の割烹着。清潔感を大切にしており、汚れたらすぐ着替える。

### 医療・薬師

- 茶衣着スタイル。ゆったりとして細かい作業がしやすい。
- 薬草・道具入れの袋を複数持つ。
- 清潔を保つため白系か薄い色の生地を好む。

**セリ**：薄い藍色の茶衣着。清潔さを保つことを重視。

### 運営・管理

- 作務衣だが、比較的きれいなものを着る（集落の代表と交渉する機会があるため）。
- 帳簿・書記道具を入れる袋を肩から下げる。

**ドウ**：清潔な生成りの作務衣。訪問者があると上着を一枚羽織る。

## 冬用防寒着

### 重ね着の体系（内側から外側へ）

**第一層：肌着**
大麻または亜麻の厚手の布を体に巻く形。足袋の内側に羊毛の靴下を重ねる。

**第二層：作務衣（冬仕様）**
夏物より厚手の生地に変える。裏地に羊毛の薄い布を縫い込む「裏打ち」をする者もいる。

**第三層：防寒の羽織もの**

| 種類 | 形状 | 素材 | 用途 |
|------|------|------|------|
| **綿入れ半纏**（はんてん） | 短い丈・袖あり | 植物繊維の外布＋内側に草綿や羊毛端材を詰める | 最も普及。動きやすく保温性が高い |
| **道中着** | 膝下まであるコート状 | 厚手の植物繊維か獣皮 | 旅・野外向け。雨風も防ぐ |
| **陣羽織風（袖なし）** | ベスト状 | 獣皮か骨甲板を縫い込んだ厚布 | 腕の動きを妨げない。野廻り・作業向き |
| **覆い頭巾** | 頭から首を覆う | 羊毛か厚手の植物繊維 | 首の保温が体温維持に最も効果的 |

### 詰め物素材

- **草綿**：綿花に近い植物の繊維。温帯域で採取可能
- **羊毛の端材・刈り落とし**：牧畜集落からの交易品
- **草毛獣の毛**（将来の伏線）：ミルクの子孫が繁殖管理されるようになれば、拠点独自の詰め物素材になりうる
- **乾燥させた草・葉を布で包んだもの**：最も安価な庶民的な代替手段

### 職能別の違い

**野廻り隊**：袖なしの陣羽織風＋覆い頭巾が基本。袖があると弓や罠作業・木登りの邪魔になる。道中着は移動時のみ羽織り、作業時は脱ぐ。

**調理・室内担当（ハナなど）**：綿入れ半纏で十分。屋内なので厚着より動きやすさを優先。

**夜間見張り（静止する）**：綿入れ半纏に加えて道中着か、毛布代わりの大きな布をそのまま羽織る。夜中の静止は最も冷える条件のため防寒が重要。

**建設・大工（クワ・ケンなど）**：体を動かして熱が出るため薄着でいることも多い。休憩時に半纏を羽織る。

### 拠点での普及状況

建設期（第1部前半）は各自が集落から持ち込んだもので対応する。拠点として冬着を揃えるのは第1部後半以降。最初の冬は物資支援で届いた羊毛の端材をセリとハナが分担して半纏に仕立てる、という場面が自然に生まれうる。

## 履物

### 基本スタイル

草履や下駄といった軽い履物は日常の室内・集落内で使うことはあるが、外出・野外作業では足を確実に守れる履物が必要になる。危険生物の出没や不整地の増加に伴い、足元の防護は生命に直結する。

**標準的な外出用履物**：足袋を発展させた厚底のブーツ。足首から膝下くらいまでを覆う高さのものが主流。指が分かれた足袋の形状を保ちながら、周囲を厚い素材で固め、底に骨甲板を貼って耐久性を高めた構造。

**素材**：
- 外側：大型獣の皮（鞣し加工）または厚く織った植物繊維の複数層
- 内側：柔らかな植物繊維の布（足袋と同様の仕立て）
- 底：骨甲薄板を数枚重ねて縫い込んだ硬底。捕縛蔦の棘や岩場での滑りを防ぐ

**つま先の構造**：足袋と同様に親指と他の指が分かれている。これにより地面の感触を感じながらも保護できる。木登りや岩場での踏ん張りにも有利。

**締め方**：足首から脛にかけて紐で締め上げる。紐の本数と位置は職能によって異なり、使い込むほど自分の足に馴染んで形が決まってくる。

### 職能による違い

| 職能 | 特徴 |
|------|------|
| 野廻り・斥候 | 軽量重視。底は薄めで地面の感触を活かす。足首の締めをきつくして固定する |
| 罠師・大工 | 底厚重視。釘・棘を踏んでも貫通しない厚さ。膝下まで覆う高さ |
| 農業・日常 | 底が薄め・高さも低め。集落内では草履や布製の低いものを使うことも |
| 医療・調理 | 室内では足袋のみ、外出時は標準のブーツ |

### 修繕と入手

底の骨甲板は消耗するため定期的な交換が必要。骨甲加工の技術を持つ職人がいる集落では修繕できる。交易品としても流通する。拠点での自前修繕はクワとガンが担当している。

## 素材と入手事情

| 素材 | 入手方法 | 特徴 |
|------|---------|------|
| 亜麻（リネン相当） | ミナシロ方向の農地で栽培 | 最も普及。丈夫で通気性が良い |
| 苧麻（ラミー相当） | 交易品 | 光沢あり、上質品に使用 |
| 大麻（ヘンプ相当） | 広く栽培 | 最も安価・丈夫。ロープ・下着にも |
| 草絹 | ハラダ方向の森縁 | 光沢と耐久性を兼ね備えた希少素材 |
| 羊毛 | 牧畜集落から交易 | 防寒用。冬の上着・靴下に |
| 骨甲薄板 | 大型獣から加工 | 当て革・補強材として縫い込む |

## 携帯灯り

### 骨甲灯（こっこうとう）

雨天・強風に耐えられる携帯灯り。日本の提灯に相当するが、素材が異なる。

**構造**：
- 大型獣の骨甲を薄く削って半透明にした板を三〜四面に張り、内部に油皿を置く
- 骨甲は防水性があるため雨に濡れても壊れない
- 底面は金属（銅）または厚い骨甲板で風を遮る
- 上部に取っ手を付けて手で持てるようにする

**特徴**：
- 強風下では炎が揺れるが、風で消えにくい（完全密閉でないため換気される）
- 暴風雨では炎が消える可能性があるため、予備の火種（火打ち石）を携行するのが常識
- 遠出・夜間見張り・緊急時の二人以上での行動では複数持ちが基本
- 骨甲の厚みによって透過光量が変わる。薄いほど明るいが脆い

**入手**：
- カネヅカの職人が製造した品が交易品として流通
- 拠点では第1部中盤以降、クワが修繕・製作できる

**松明との違い**：
- 松明は明るいが雨に弱く、両手がふさがる
- 骨甲灯は片手で持てて防水だが、製造コストが高い
- 普段の見張りは骨甲灯、緊急時・多人数での作業は松明と使い分ける

## 拠点「三ツ辻」での服装事情

建設期（第1部前半）は各集落から持ってきた衣服のまま。補修はできるが新調は難しく、次の物資支援に頼るしかない。

- リュウが採集してくる植物から染料を作れる（ただし試行錯誤）
- 草毛獣の毛が繊維素材として利用できることが後に判明（第3部への伏線）
- 破れや汚れが目立ち始めるのは2〜3ヶ月後から
