# 小説家になろう 投稿計画

## 対象作品

- 作品タイトル: `辺境拠点日誌　〜三集落の中間でのんびり（？）野廻り〜`
- 掲載先想定: `小説家になろう`
- 想定ジャンル: `SF > 空想科学`

## 基本方針

- `空想科学` は母数が大きい主流カテゴリではないため、一度の大量投下よりも `継続的な更新露出` を重視する。
- 初回公開時に `3話以上` を読める状態にして、世界観と作品の方向性を掴んでもらう。
- その後は `同じ時間帯で定時更新` し、読者に更新習慣を作ってもらう。
- 夜の読者が多い時間帯を狙い、更新時刻は `20:10 JST` を基本線にする。

## 以前に出した運用方針の記録

以前の提案では、次の運用を推奨した。

1. 初回公開は `金曜か土曜の19:10〜22:10 JST`
2. 初日に `3〜5話まとめて公開`
3. その後 `10〜14日間は毎日1話、同じ時刻に予約投稿`
4. 時刻は基本 `20時台固定`、ずらすなら `19時台後半` か `21時台前半`
5. 2週目以降は `週3〜5回の定時更新` に移行

補足メモ:

- 初期案として、`金曜 20:10 に1〜3話公開`、同日 `21:10` に4話、`22:10` に5話、以降は毎日 `20:10` 更新という流れを提案済み。
- 空想科学カテゴリでは、`初動のまとまった読書量` と `連日更新による再露出` の両立が重要。

## 各話の目安

- 初期話数の理想文字数: `3,000〜4,000字`
- 連載安定後の標準: `2,500〜3,500字`
- 節目の回やイベント回: `4,000〜5,000字` でも可

## 作品の見せ方メモ

- この作品の強みは、`派手な能力` よりも `土地・物流・人員配置・生活立ち上げ` の面白さにある。
- そのため、投稿時は本文の静かな魅力を損なわず、あらすじでは `何を楽しむ作品か` を明快に示す。
- タイトルはすでに決定済みのため、集客面では `あらすじ` と `キーワード` の整備を重視する。

## 掲載時の実務チェック

- 予約投稿で各話を `20:10` に設定する。
- 初日公開分 `第1話〜第3話` は事前に整えておく。
- 初速フェーズ分 `第12話まで` は、公開前にできるだけ下書きまたは推敲済みにしておく。
- あらすじとキーワードは、`拠点建設` `開拓` `集落運営` `空想科学` が伝わる形にする。
- 公開後は `PV` だけでなく `ユニークアクセス` も確認する。

## 運用メモ

- もし初動が弱くても、空想科学カテゴリでは即断しない。`10日連続更新` までは様子を見る。
- 反応が良かった場合も、更新時刻をむやみに変えない。
- 読者の入口として重要なのは `第1話の導入` と `第3話到達時点での作品理解`。
- 必要に応じて、別途 `あらすじ案` `キーワード案` `各話サブタイトル調整案` を作る。

### 原稿準備

- `第1話〜第3話` を推敲済みにする。

- 第1話冒頭の数段落で、舞台と状況が読み取りやすいか見直す。

### 投稿設定

- タイトルを正式表記で入力する。  
  `辺境拠点日誌　〜三集落の中間でのんびり（？）野廻り〜`
- ジャンルを `SF` の `空想科学` に設定する。

### 公開後確認

- 第1話公開後に、表示崩れや誤字脱字がないか投稿画面で確認する。
- `第3話公開後` の時点で、導線として違和感がないか読み返す。
- ブックマーク、評価、感想の有無だけでなく、アクセス推移もあわせて見る。
- 数日で判断せず、まずは `初速フェーズ完走` を優先する。

## 前書き・後書き運用方針

### 基本方針

- この作品では、`毎話の前書き・後書きは入れない` 方針を基本とする。
- 理由は、連続読みに向いた作品であり、前書きや後書きが多いと `読書のリズム` と `没入感` を崩しやすいため。
- 特に `前書き` は本文に入る前の流れを止めやすいので、常用しない。

### 推奨運用

- `第1話` は前書きなし・後書きなし
- 通常回は前書きなし・後書きなし
- `章の区切り` や `更新間隔が空いたとき` のみ、短い後書きを使う
- 使う場合も `1〜3行程度` に留める

### 入れてよいケース

- 章の始まりや終わりで、区切りを軽く伝えたいとき
- 更新がしばらく空いた後に、短い近況やお礼を添えたいとき
- 投稿上の補足が必要なとき
- 今後の更新予定を簡潔に伝えたいとき

### 避けたい使い方

- 毎話の定型的なお礼
- 毎話の制作裏話
- 本文で自然に伝わる内容の補足説明
- 長い次回予告

### 使うなら後書き優先

- 前書きは没入前に読者を止めるため、必要性が高い場合だけ使う
- 補足を入れるなら、読み終わった後に見られる `後書き` を優先する

### 文例

後書きの短い例:

- `ここからしばらく、拠点の立ち上げ作業が続きます。`
- `次話も20:10ごろ更新予定です。`
- `第1章前半の山場に入っていきます。`

前書きの短い例:

- `第1章 建設期の始まりです。`
- `ここから数話、拠点の基礎固めが中心になります。`
