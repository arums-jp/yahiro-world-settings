# ヤヒロ環境保安部の装備仕様

**本ファイルの位置づけ**：事故前（約2,000年前）にヤヒロ船内に存在した保安組織と、その装備の仕様を定義する。01〜08の確定値と矛盾しないよう構成しているが、内容自体は新規設定である（従来の資料に船内保安組織の記述は存在しなかった）。

**主な用途**：「辺境拠点日誌」続編（環境保安部要員を主人公とする物語）の基礎資料。

────────────────────────────────────────

## 1\. 組織と設計思想

### 1-1. 防衛機能の二層構造

| 対象 | 担当 | 性質 |
| --- | --- | --- |
| **船外の脅威** | 防空システム「カグツチ」 | 完全自動・無人。隕石・宇宙塵・想定外の接触 |
| **船内の脅威** | **環境保安部**（人間） | 例外処理と現場判断を要するもの |

船外の脅威は自動兵器が担当していたため、**環境保安部は対外戦闘の想定を一切持たない**。これが「過剰な武装が存在しない」理由の第一層である。

### 1-2. 正式名称と呼称

*   **正式名称**：ヤヒロ環境保安部（部門により生物管理課・防疫課・災害対応課ほか）
*   **現場通称**：**防人（さきもり）** ——古代日本の辺境守備兵に由来。「境を守る者」の意
*   **現代の住民の伝承**：**防ぎ人（ふせぎびと）**。災いを退ける神代の守り手として神話化されている（語り部の伝承に断片的に残存）

### 1-3. 四つの仮想敵

| # | 仮想敵 | 内容 | 頻度 |
| --- | --- | --- | --- |
| ① | **逸脱個体（デヴィアント）** | B番号ノードの抑制信号に従わない個体。生まれつきの外れ値、病気・負傷で回避行動を失った個体、施設からの逃走個体 | **日常業務**。全船で年間数十件 |
| ② | **生物学的封じ込め対象** | 暴走した設計生物、逃走した研究検体、病原体 | 稀。ただし発生すれば船の存亡に関わる |
| ③ | **事故・災害** | 区画火災、減圧、浸水、構造崩落、設備異常 | **業務量の大半**。保安部の本質は消防・救助 |
| ④ | **対人（保護対象）** | 孤立・自傷・パニック。犯罪は逃げ場がないため検挙容易 | 制圧ではなく保護の対象 |

**①が続編の中核**：クストス稼働時代、居住域への動物侵入はB番号ノードの信号が99.9%自動で防いでいた。残る例外を処理するのが生物管理課の日常業務だった。事故から2,000年を経た現在、**全ての危険生物が「信号に従わない個体」になっている**（→ 辺境拠点日誌／危険生物設定「クストス停止後の2000年間——自然選択による変異」）。当時の例外処理が、現代では世界の標準になっている。

### 1-4. ドクトリン「殺さず、止める」

*   搭載生物は生態系の構成要素であり、**殺せば補充できない**
*   致死武器の使用は船体・配管・気密を損傷しうる。区画一つの損失が数万人の生活を止める
*   したがって装備は**非致死を基本とし、致死出力は封じ込め時の例外運用**とする
*   「殺すための道具は持たない。**止めるための道具は最高性能**」

## 2\. 火薬を採用しなかった理由

| 火薬の問題 | 閉鎖環境での帰結 |
| --- | --- |
| 燃焼ガス（CO・NOx・微粒子） | 区画の空気は循環系で全船共有。**発砲が空調系を汚染する** |
| 経年劣化 | 主観300年の航行＋長期保管に耐えない |
| 弾薬＝質量 | 移民船は質量が全て。消耗品の大量搭載に動機がない |
| 出力が固定 | 非致死と致死を撃ち分けられない＝ドクトリンに反する |
| 補給不能 | 硝石・硫黄の供給網を船内に持つ意味がない |

**採用された方式：電磁投射（コイルガン系）**

*   動力がサンド・クリスタル（→3節）。**現代でも補給可能**
*   出力が連続可変。1挺で「警告→制圧→貫通」を撃ち分けられる
*   燃焼しない。ガスも炎も出さない。発砲音は金属の唸りのみ
*   **弾体は質量体であればよい**。規格弾がなくても鉄片・小石で撃てる

**指向性エネルギー兵器を主武装にしなかった理由**：

*   大気中で減衰する（ヤヒロは霧の発生が多い）
*   焼灼では運動量を奪えず、突進する大型獣を止められない
*   密閉環境での引火リスク

→ レーザーは精密切断用途（車載）に限定。**明確な弱点を持つ装備**として位置づける。

## 3\. 動力：サンド・クリスタル

08\_作者専用・裏設定より：静的MTMの蓄積に最適化された人工結晶体。直径0.1〜0.5mmの半透明砂粒、硬度モース12相当。

**これは電気化学セルではなく、高密度物質へのエネルギーの物理的定着である。** したがって：

*   電解液の劣化が起きない
*   自己放電の機構がない
*   電極の膨張収縮がない

→ **2,000年放置しても劣化しない蓄電媒体**。動力系の最大の弱点が、既存設定によって解決されている。

### 3-1. 運用形態

| 形態 | 内容 | 現代での状況 |
| --- | --- | --- |
| **砂状（原体）** | 未成形のサンド・クリスタル。密封保管 | 保管庫内の備蓄はこの形態。**無傷** |
| **燃料ペレット** | 樹脂バインダーで固めた5〜10mmの粒 | **バインダーは有機材料のため経年で崩壊**。多くは砂に戻っている |
| **蓄電セル** | 装備に装填する筐体。砂を充填して使用 | 筐体はセラミック・金属製。健全 |

**重要**：現代の集落・外部市には「サンド・クリスタル」が古い構造材の破片として流通している（08に既記載）。バインダーが崩れて使えなくなったペレットは**屑として扱われることが多いが、篩って砂を回収すれば動力として使える**。主人公が現地で補給できる根拠。

### 3-2. 充填

蓄電セルへの充填には**充填機（車載級の装置）が必要**。個人携行装備だけでは充填できない。したがって移動電源／充填機が全装備の生命線となる。

## 4\. 2,000年後も稼働する理由

### 4-1. 設計側：有機材料と摺動面を「持たない」

08\_裏設定の「自律運用優先」思想——**数千年の世代間航行を想定した多重冗長設計**——により、長寿命化は設計要件の第一項だった。

| 通常の設計 | ヤヒロの設計 | 効果 |
| --- | --- | --- |
| 潤滑油＋転がり軸受 | **人工筋（電歪・磁歪アクチュエータ）** | 摺動面が存在しない＝摩耗も真空焼付きもない |
| ピン＋ベアリング関節 | **弾性関節（コンプライアント機構）** | 金属・セラミックの弾性変形で屈曲。軸受不要 |
| ゴムのOリング | **金属ガスケット** | 加水分解しない |
| 樹脂被覆の配線 | **セラミック絶縁** | 経年で割れない |
| 化学電池 | **サンド・クリスタル** | 原理的に劣化しない |
| 常時圧縮のコイルばね | **無負荷保管＋形状記憶合金** | クリープ・応力緩和を回避 |
| 装甲・構造材 | **MTMアロイ**（経年劣化ゼロ／02に既記載） | 2,000年経っても傷一つない |

**描写上の帰結**：外骨格は「モーターとギアの機械」ではなく**「金属とセラミックが伸縮する構造体」**。作動音は駆動音の唸りではなく、**きしみと軋み**になる。

### 4-2. 保管側：保安装備庫「蔵（くら）」

**真空・極低温は採用していない。** 真空は摺動面の凝着（コールドウェルディング）とアウトガスによる高分子の脆化を招き、極低温は高分子のガラス転移による脆性破壊と、取り出し時の熱衝撃・結露を招くため。

| 項目 | 仕様 |
| --- | --- |
| 構造 | MTMアロイ一体成形区画。開口部は一箇所 |
| 雰囲気 | **乾燥アルゴン陽圧**（約1.1気圧）。漏れは内側から外へ吹き出すため汚染が侵入しない |
| 温度 | **安定低温 −5℃。変動幅±1℃以内**を2,000年維持（劣化を決めるのは絶対温度よりサイクル数） |
| 電力 | 静的MTM備蓄からの微量供給。**保存槽区画と同一系統** |
| 維持機構 | **材料修復ナノマシン**が低速で巡回し、微小欠陥を継続的に補修 |
| 冗長性 | 同一装備を3セット格納（1セット生き残れば運用可能という設計思想） |

**要点**：この施設は装備を「保存」していたのではなく、**2,000年間ずっと整備し続けていた**。倉庫ではなく無人の整備工場である。主人公が目覚めた時点で装備が使える根拠——**装備は寝ていなかった**。

**前例**：辺境拠点日誌 第104・106話で、保存槽が2,000年間人体を生体維持していたことが確定している。同時に「多くは空だった。一部は蓋が割れて壊れていた」とも描写されている。**維持は完全ではなかった**。装備の生存率もこれに準じる。

### 4-3. 生存率（確定）

| 状態 | 該当装備 | 物語上の役割 |
| --- | --- | --- |
| **完全稼働** | 携行電磁投射器「静」、多目的カッター「割」、感覚拡張装置 | 主人公の日常装備。確実に動く |
| **部分稼働** | 外骨格「鎧」（出力85%・稼働時間28%）、鎮静投射器「鎮」（薬剤の75%が失活） | **性能に上限がある**＝緊張の源 |
| **一発限り** | プラズマ焼却器「祓」（累計90秒分）、重電磁投射砲「貫」（各1基のみ生存） | 切り札。最終決戦用 |
| **死亡** | 3セットのうち2セット。予備部品の大半 | 部品取り。**替えがない理由** |
| **原理的に無効** | 抑制信号発振器「鈴」 | 装備は健全だが**世界が変わった** |

## 5\. 第1層：個人携行装備

単独で行動できる最小構成。総重量 約14kg（外骨格なしで携行可能）。

### 5-1. 制圧投射器「静（しずめ）」

**制式：携行型電磁投射器**／主武装

| 項目 | 仕様 |
| --- | --- |
| 質量 | 4.2kg |
| 出力段 | ①警告 ②制圧 ③貫通（連続可変） |
| ②制圧 | ゲル弾20g／約141m/s／**約200J**／有効射程50m |
| ③貫通 | 金属弾10g／約775m/s／**約3,000J**／有効射程300m |
| 弾体 | 規格弾のほか、**5〜30gの任意の質量体（鉄片・小石）が使用可能** |
| 電力 | 蓄電セル1本で 貫通約40発／制圧約120発 |
| 連射 | 貫通は3発で冷却待ち約20秒。制圧は10発連続可 |
| 発射音 | 金属の唸り。破裂音なし |

**現代での評価**：貫通出力3,000Jは鎌爪竜（120〜180kg）を確実に停止させる。**弾体を現地調達できるため弾切れが起きない**——これが主人公の継戦能力の根拠。

### 5-2. 鎮静投射器「鎮（しずめ）」

| 項目 | 仕様 |
| --- | --- |
| 方式 | 圧縮ガス式（火薬不要） |
| 射程 | 25m |
| 効果 | 鎌爪竜級を8〜15秒で沈静。生体捕獲が可能 |
| 残弾 | **6発**（本来24発。75%が経年で失活） |

**有限の切り札**。薬剤は現代では合成できない。

### 5-3. 拘束網射出器「搦（からめ）」

| 項目 | 仕様 |
| --- | --- |
| 射程 | 15m／展開径4m |
| 効果 | 粘着網。逃走個体の非致死拘束。群れの足を面で止める |
| 補給 | 網体は消耗品。現地の樹脂で代用試作の余地あり |

### 5-4. 多目的カッター「割（さき）」

| 項目 | 仕様 |
| --- | --- |
| 方式 | 高周波振動ブレード（40kHz）。刃材はMTMアロイ／超圧縮重金属 |
| 刃長 | 320mm |
| 切断能力 | 鋼材20mm厚。鎌爪竜の外皮・爪を1動作で切断 |
| 稼働 | 連続8分／蓄電セル1本 |

**本来は救助工具**（構造材切断・瓦礫排除）。主人公は最後までこれを「救助道具」と呼び続ける。

### 5-5. 抑制信号発振器「鈴（すず）」

| 項目 | 仕様 |
| --- | --- |
| 方式 | B番号ノードの抑制信号（特定周波数帯の電磁波・超音波）を携行再現 |
| 本来の有効半径 | 80m（据置ノードの影響半径20〜25kmに対し、携行版は出力が桁違いに小さい） |
| **現代の反応率** | **個体の1〜2割のみ**（2,000年の自然選択で感受性が低下） |

**本作の主題を体現する装備**。装備は健全であり、故障もしていない。**世界が変わったために効かない**。第1話でこれが判明することが、物語の宣言になる。

なお、リュウの嫌音鈴（辺境拠点日誌）は同じ信号帯を偶然再現したもので、有効性の限界も同一。

### 5-6. 感覚拡張装置

| 機能 | 仕様 |
| --- | --- |
| 全周音響探知 | 半径120m。方位分解能 約2度 |
| 熱源探知 | 300m |
| 振動探知 | 地表を伝わる足音を半径80mで検出 |
| 暗視 | 実質無制限（照度依存なし） |

**戦術上の帰結**：

*   鎌爪竜の「真後ろが死角」という弱点が**主人公には存在しない**
*   鎌爪竜の陽動戦術（1頭が引きつけ、他が回り込む）が成立しない
*   **夜間戦闘という人類最大の弱点が消える**（危険生物の多くは夕暮れ〜夜明けが活動時間）

## 6\. 第2層：保安外骨格「鎧（よろい）」

本来は瓦礫排除・重量物搬送・救助用のパワーアシスト。

| 項目 | 本来の仕様 | **現状（劣化後）** |
| --- | --- | --- |
| 質量 | 68kg（装着者の実効負担はほぼゼロ） | 同 |
| 握力 | 1.8kN | 1.5kN |
| 持ち上げ | 400kg | 340kg |
| 走行 | 45km/h（短時間）／巡航25km/h | 38km/h／巡航21km/h |
| 稼働時間 | 12時間 | **3時間20分** |
| 装甲 | MTMアロイ薄板3mm | 同（**劣化ゼロ**） |

**防御性能**：針鼠狼の針（体長1.2〜1.5m／40〜60kg）は表面で弾かれる。鎌爪竜の爪も装甲面では傷をつけられない。ただし**関節部・可動部の被覆は薄く、そこを狙われれば損傷する**。

**弱点（物語上の制約）**：

*   稼働時間が本来の28%しかない。長期戦・連日運用ができない
*   関節部の人工筋は経年で出力が落ちており、**予備部品がない**。使うほど寿命が減る
*   着脱に約4分。奇襲には対応できない
*   電力食い。充填機から離れれば運用できない

**整備の前提**：関節部の応急修理・出力調整・人工筋の張り直しには**整備要員（装備整備課）が必要**。装着者単独では日常点検までしかできない。したがって外骨格の継続運用は、整備担当の同行が前提となる（→11\_主人公と続編の時系列）。

## 6-2. 二人体制での運用（前提）

本装備群は**単独運用を前提に設計されていない**。環境保安部の標準編成は、現場要員と整備要員の組である。

| 担当 | 役割 |
| --- | --- |
| **生物管理課要員（前線）** | 交戦・判断・現場指揮。個人携行装備の運用 |
| **装備整備課要員（後方）** | 整備・応急修理・電力管理・弾体製作・観測・大型装備の設置補助 |

### 運用上の帰結

| 装備 | 単独運用 | 二人体制 |
| --- | --- | --- |
| 個人携行6点 | 可 | 可 |
| 外骨格「鎧」 | **短期のみ**（整備できないため損耗が累積する） | 継続運用可 |
| 大型装備（貫・祓・喝・筋） | **不可**（設置・観測・射撃を同時に行えない） | 運用可 |
| 移動電源／充填機 | 運搬は可。運用は要熟練 | 可 |
| 弾体の現地調達 | 手配に時間を取られる | **現地の鍛冶と組んで量産できる** |

**物語上の使い方**：単独期間（→11節「時間差覚醒」）は**外骨格を痛めながら個人携行装備だけで戦う**期間になる。整備要員の合流によって初めて大型装備が選択肢に入る。

## 7\. 第3層：車載・大型装備

### 7-1. 存在理由

質量を極限まで削る移民船が重装備を積む理由は**生物学的封じ込め**に限られる。閉鎖世界で暴走した設計生物や病原体は文明を終わらせるため、ここだけは質量を割く価値があった。

**ただし配備数は極少**（全船で数十基程度）。当時から希少品である。

### 7-2. 仕様

| 制式通称 | 種別 | 質量 | 主要諸元 | 本来の用途 |
| --- | --- | --- | --- | --- |
| **貫（つらぬき）** | 重電磁投射砲 | 240kg（台架込） | 弾体500g〜2kg／約566m/s／**約80,000J**／射程1,200m／蓄電セル1本で6発／冷却90秒 | 大型個体の確実な停止。**弾体は鉄塊・石塊で代用可** |
| **祓（はらい）** | 熱プラズマ焼却器 | 240kg | 射程12〜30m／扇状幅8m／**残存稼働 累計90秒分** | 汚染区画・巣・卵塊の焼却。「殺すため」ではなく「封じるため」 |

### 7-3. 「喝」の設計上の重要性

抑制信号（生物学的な感受性に依存する機能）は2,000年の自然選択で無効化されたが、**物理的な音圧は進化で回避できない**。鼓膜と平衡感覚はDNA設計の対象外だったため、感受性の低い個体にも等しく効く。

**「機能は失われたが、性能は通じる」**——本作のテーマを装備一つで体現する。

## 8\. 運搬手段

古代の作業車両は稼働しない（蓄電体は健全でも、車輪・懸架・関節の消耗部が保たない）。したがって大型装備の移送は**牽引**による。

### 8-1. ウロジカによる牽引

危険生物設定より：肩高2.0〜2.4m／体重200〜300kg／**騎乗・牽引の両対応**／食性が広く飼葉不要／蹄が悪路・急斜面に対応。

| 項目 | 内容 |
| --- | --- |
| 編成 | ウロジカ2頭＋牽引台車 |
| 積載 | **1回に大型装備1基＋移動電源** |
| 移動速度 | 4〜5km/h（荷駄時）。悪路・急斜面も踏破可 |
| 制約 | **繁殖が困難で頭数を増やせない**（既存設定）。したがって編成は増やせない |

**絵としての要点**：2,000年前の重火器を、変異した鹿に牽かせて運ぶ。

### 8-2. 外骨格による牽引

可能だが電力を消費し、稼働時間3時間20分をさらに削る。**短距離・緊急時のみ**。

### 8-3. 運用上の帰結

大型装備は「持ち歩けない」。**使う場所を事前に決めて運び込む**必要がある。これが物語構造上の制約になる：

*   遭遇戦では個人携行装備しか使えない
*   大型装備を使うには**偵察→判断→移送→設置**の手順が必要
*   したがって「情報」と「準備」が価値を持つ（前作の血脈を軽く継承できる）

## 11\. 執筆時の注意

### 書いてよいこと

*   装備の性能で圧倒する描写（**性能で圧制**）
*   電力・薬剤・稼働時間の消費を数値で示す
*   「本来は救助道具です」という主人公の一貫した認識
*   大型装備の移送・設置に手間がかかること

### 書いてはいけないこと

| 禁止 | 理由 |
| --- | --- |
| 収納・異空間系の解決 | 存在しない。大型装備は必ず牽引が必要 |
| 抑制信号「鈴」で群れを一掃する | **1〜2割しか反応しない**。無効であることが物語の前提 |
| 装備が壊れないこと | MTMアロイ部以外は消耗する。特に外骨格の関節 |
| 火薬・薬莢・硝煙の描写 | 電磁投射は燃焼しない。音は金属の唸り |
| 具体的なMTM残存量への言及 | M005の確定値に踏み込まない |
| 因果の泡・カグツチ・セカンドの核心 | 意図的に保留中の謎（U001ほか） |
| 装備がフルセットで揃っていること | **3セットのうち2セットは死んでいる** |

### 数値の扱い

*   地の文では「約」で保護する（例：「射程は三百歩ほど」）
*   主人公の報告・独白では正確な数値を使ってよい（保安部の職業性を示す）
*   住民には理解できない単位なので、**会話では換算しないまま提示する**のが自然
