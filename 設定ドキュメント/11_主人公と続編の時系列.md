## 1. 主人公二名

### 1-1. 前線：出石 啓悟（イズシ ケイゴ）

| 項目 | 設定 |
|---|---|
| 性別・年齢 | 男・**28歳**（冷眠時。生物学的に変化なし） |
| 所属 | ヤヒロ環境保安部 **生物管理課** |
| 階級 | **二等保安士**（現場の中堅実務者。班を率いるが指揮官ではない） |

| 役割 | 交戦・判断・現場指揮。**無双の焦点** |

**背骨＝報告先を作ること**

招集命令には報告先が記載されているが、**その部署は存在しない**。保安部の規則では、報告できない場合は現場最上位が記録を保全し、指揮系統が回復した時点で提出する。彼はこれに従っている。

> **彼は、いつか提出するために記録を取り続けている。**

これにより以下がすべて説明される：

| 要素 | 説明 |
|---|---|
| なぜ戦うのか | 招集に応じた業務。世界を救う意図はない |
| なぜ記録を取り続けるのか | 提出義務が消滅していない |
| なぜ感情を出さないのか | **同僚30名の死も、彼の中では「まだ報告していない」状態にある** |
| 終盤の着地 | 報告先が見つかった時、**初めて彼は悲しむことを許される** |

数年後、噂で三ツ辻を知る——「**記録を続けている拠点がある**」。会う必要はない。その存在を知るだけで、彼の中で提出先が成立する。前作が『辺境拠点日誌』というタイトルで終わったこととの共鳴がここで完成する。

**唯一の弱点：人が減ることへの反応**

彼は**非番で寝ていて30名を救えなかった**。その結果、住民の死に対して不釣り合いに強く反応する。「一名、失いました」と記録に書くことを極端に嫌がる。

これが行動原理に一貫性を与える：

- **人が死なないなら放置する**（無人地帯の牧夫3体を見送る → 10節）
- **人が死ぬなら過剰に動く**（規則の範囲を超えかける）

「倒せるが倒さない」と「絶対に死者を出さない」が同じ根から出ている。

**話し方**

- 敬語。簡潔。報告調
- **数値を正確に言う**。「射程三百m」「稼働、残り二時間十分」
- 住民に通じない単位を換算しない（→09）
- 硬すぎて住民が緊張する

**規則との関係**：規則を盾にしているのではなく、**規則が判断を早くしてくれる**から従っている。迷う時間が人を死なせると知っている。

## 2. 名前の扱い

### 2-1. 古代人は姓名を持つ

**二千年前の乗員は姓＋名を持っていた**（日本文化圏の慣習）。文明崩壊の二千年で命名は一語に簡略化され、現代の住民は「カイ」「スズ」「ドウ」のように名だけを持つ。

したがって**姓名を持つこと自体が「古代人」の標識になる**。

**アオイとの整合**：前作でアオイの姓が語られなかったのは、保存槽の表示が名のみだったか、彼女が現地の慣習に合わせて名だけを告げたためと解釈する（第145話で「三ツ辻のアオイ」と呼ばれるようになる流れと一致）。矛盾は生じない。

### 2-2. 住民は姓名を扱えない

住民には「名前が二つある」という概念がない。

> 「イズシ、ケイゴ」
> 「……名前が、二つあるんですか」
> 「姓と、名です」
> 「ふたつ、要るんですか」

住民は片方だけを採用する（「ケイゴさま」「イズシの人」など、集落によって揺れる）。**この揺れをそのまま書くと、世界の断絶が一言で伝わる。**

### 2-3. 二人の呼び合い方

職業的距離を保つため、**互いに姓＋さん**で呼ぶ。

- 那美 → 「**出石さん**」
- 啓悟 → 「**高原さん**」

名で呼び合わないことが、恋愛関係にないことを地の文なしで示す。**終盤で呼び方が変わるかどうかは、作者の裁量に残しておく。**

### 2-4. 関係の方針

**同僚関係を貫く。** 恋愛の焦らしはストレス源になりやすく、本作の方針（ストレスの少ない爽快感）と逆行する。また「二千年前からの同僚」という関係の方が、**30名を失った重みを共有できる**。

## 3. 時間差覚醒

**二人を同時に起こさない。** これが導入部の構造を決める。

電力が細く覚醒に約1年かかる状況で、システムは**条件が最良の1名のみ**を復旧させた。二人目の槽も生きているが、システムは「電力不足」と判断して保留した。

> **啓悟が、自分の判断で那美を起こす。**

### 3-1. 導入部の段階

| 段 | 内容 |
|---|---|
| 1 | 啓悟が目覚める。**区画に一人**。同僚30名は失われている |
| 2 | 生存している槽が1つだけあると分かる（高原 那美・二等技士） |
| 3 | **電力を使えば、装備の充填が数ヶ月遅れる**。牧夫は既に動いている |
| 4 | 規則は「現存要員の確保」を優先事項に挙げている。**啓悟は即座に決める** |
| 5 | 空白の数ヶ月。啓悟は**充填不足の装備で単独行動**する |
| 6 | 数ヶ月後、那美が目覚める。傷んだ装備を見て怒る |

### 3-2. この構造で得られるもの

- 「起きたら一人だった」重さを**保持したまま**、相棒を獲得できる
- 啓悟の人物像が**行動で示される**（迷わない。規則が判断を早くする）
- **人を選んだ代償として、装備が不完全**。第1体との戦いが苦しくなる理由が設定から出る
- 前作第107話「起こすか、起こさないか」の**内側からの反転**。あちらは住民が数話悩んだ。こちらは当事者が即決する
- 那美の初登場が「怒る」になる。関係性が一言で立つ

> 「外骨格の左膝、人工筋が伸びきってます。何をしたんですか」
> 「業務です」
> 「業務で壊すなら、先に私を起こしてください」
> 「起こしました」
> 「……遅いです」

### 4-1. この配置が解決すること

**「なぜ啓悟は前作の危機を助けなかったのか」** → **まだ解凍中だった。** プロットホールが消える。

**「なぜ啓悟は三ツ辻を知らないのか」** → 目覚めた時点で危機は既に終わっており、しかも約1,000km離れている（→5節）。

啓悟が対処するのは三ツ辻の危機ではなく、**同じ信号が引き起こした副作用**——目覚めた牧夫のほうである。

### 4-2. 覚醒地

三ツ辻から**約900〜1,000km**（地表の最大距離は約1,414km＝ほぼ反対側）。温帯域の辺縁に位置し、物語の進行とともに温暖域の廃墟地帯（第4体「一号」の territory）へ向かう。

**居住域 → 廃墟**という舞台の進行が、そのまま物語の進行になる。

## 6. 古代技術を隠さない方針

なろうの定番から外れるが、**この設定では隠すほうが不自然である**。

### 6-1. 根拠

| # | 理由 |
|---|---|
| ① | **隠す動機が存在しない。** 典型的ななろうで力を隠すのは、それを奪う人間がいるからである。本作には**人間の敵がいない**。最初にそう決めた時点で、隠す理由が設定から消えている |
| ② | **職業倫理として隠す発想がない。** 保安部要員は公務員であり、装備は権限の可視化そのもの。消防士が消防服を隠さないのと同じで、隠すことが規則違反になる |
| ③ | **ストレスの少ない爽快感に直結する。** 「隠す→バレる→驚かれる」はカタルシスの遅延。最初から堂々と使い、最初から敬意を得るほうが本作の方針に合う |
| ④ | **物語が回る。** 隠さないから協力が即座に得られ、サンド・クリスタルの補給網と情報網が最初の数話で手に入る |

### 6-2. 各勢力の反応

| 相手 | 反応 | 使い道 |
|---|---|---|
| **住民** | 「防ぎ人」の伝承と一致 → **神格化される** | 啓悟が全力で否定し、訂正しても直らない。コメディと人物像 |
| **語り部** | 伝承の実物が現れた（前作の重要職能） | 最も大きく反応する。彼の記録と伝承の突き合わせ |
| **隊商** | 商売になる。護衛依頼が殺到 | 補給網と移動手段が手に入る |
| **集落** | 期待と依存。「全部やってくれ」 | **唯一の摩擦源**（→6-3） |

### 6-3. 摩擦源は「期待」のみ

人間の敵はいないが、**期待という摩擦**は残る。悪役のいない物語で緊張を作る唯一の場所である。

> 「あの牧夫も、倒してくれませんか」
> 「その個体は、人里から八十km離れています。任務の範囲外です」
> 「でも、倒せるんでしょう」
> 「倒せます。やりません」

### 6-4. 技術流出は設定的に安全

- **サンド・クリスタルは拾える**（現地流通／→09）
- しかし**蓄電セルと制御機構が作れない**。現地の技術水準では電磁投射は再現不能

流出しても実害がない。ただし「**原理を知る**」ことは起こる。前作のリュウがやったように、誰かが理解を始める。これは害ではなく、**この世界の技術が再び動き出す種**として前向きな余韻に使える。

### 6-5. 「防人（さきもり）」伝承とのズレ

住民の伝承は辺境守備兵を想起させるため、**男の武人**を思い描いている。実際に現れるのは姓名を持つ二人組で、しかも整備担当は若い女性である。

伝承と実物のズレを、素朴な可笑しさとして使える。

## 7. 執筆時の注意

### 書いてよいこと

- 装備の性能で圧倒する描写（**性能で圧制**／→09）
- 残弾・電力・稼働時間の消費を数値で示す（那美が告げる）
- 古代技術を堂々と使い、神格化を否定し続ける
- **倒せるのにやらない**という業務判断
- 姓名を持つことによる住民との断絶

### 書いてはいけないこと

| 禁止 | 理由 |
|---|---|
| 二人を同時に覚醒させる | 導入部の構造が崩れる（→3節） |
| 那美を戦闘で活躍させすぎる | 無双の焦点がぼやける |
| 恋愛関係に進める | 方針として同僚関係を貫く（→2-4） |
| 啓悟が事故の真相を知っている | **非番だった**。因果の泡・カグツチの核心は温存 |
| 三ツ辻と早期に接触させる | 情報伝達に2〜4年かかる（→5節） |
| 古代技術を隠す展開 | 動機が設定から存在しない（→6節） |
| 住民が姓名を正しく扱う | 現代の命名慣習は一語 |
| 30名の死を序盤で情緒的に処理する | **終盤まで「まだ報告していない」状態に置く** |

### 感情の配分

- **那美が悼み、啓悟が後回しにする。** これを最後まで維持する
- 啓悟が崩れるのは**報告先が成立した時**のみ。一度だけ
- 湿っぽくしない。啓悟は悲嘆を「確認作業」として処理する

> 「同僚は」
> 「三十一名、記録上は同じ区画にいました。現存、二名です」
> 「……それは」
> 「報告書に書きます。今は、獣の話をしましょう」
