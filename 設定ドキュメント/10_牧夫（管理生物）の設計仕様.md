# 牧夫（管理生物）の設計仕様

**本ファイルの位置づけ**：事故前のヤヒロに配備されていた生態系管理用の設計生物「牧夫」と、2,000年後の現存個体を定義する。01〜09の確定値と矛盾しないよう構成した新規設定。

**主な用途**：「辺境拠点日誌」続編の敵設定。および**TRPGシナリオ用の脅威在庫**（→10節）。

**重要な方針**：正史で処理されるのは4体のみ。**約43体を未確認・休眠状態のまま残す**ことで、他作品・他シナリオが正史に触らずに使える余地を確保する。

────────────────────────────────────────

## 1\. 設計目的と正体

### 1-1. 何のために作られたか

ヤヒロは自己完結した生態系を維持するため、改良家畜と野生原種の双方を搭載した。その**誘導と群れ管理**を担う専用の設計生物が牧夫である。

*   家畜の群れを目的地へ誘導する（牧畜の自動化）
*   野生原種の群れを居住域から遠ざける（B番号ノードの補助）
*   生態系の個体数を局所的に調整する

**位置づけ**：クストス → 標塔（メインノード）→ B番号石柱（サブノード）という制御階層の、**最末端の可動端末**。石柱が「動けない調整装置」であるのに対し、牧夫は「歩いて現場へ行く調整装置」だった。

### 1-2. 呼称の三層

| 層 | 呼称 |
| --- | --- |
| 保安部の記録 | 「牧夫」（型式名）。個体は型式番号で管理 |
| 現代の住民 | 「群れ主（むれぬし）」「首（かしら）」 |
| 個体名 | 土地ごとの伝説名（「灰の親」「三つ首」など） |

主人公は型式番号で呼び、住民は伝説名で呼ぶ。**両者が同じものを指していると判明する瞬間**を見せ場に使える。

## 2\. 身体仕様

| 項目 | 仕様 |
| --- | --- |
| 体長 | 3.0〜3.5m（四足。長い首と低い胴） |
| 体重 | **400〜600kg** |
| 外見 | 灰白色の粗い体毛。頭部後方に硬質の隆起（信号器官）。眼は小さく、視覚より聴覚・振動感知に依存 |
| 走行 | 巡航12km/h、短距離35km/h。**機動よりも持久に振られた設計** |
| 咬合・打撃 | 大型獣を制圧できるが、殺傷を目的とした武器形質は持たない（**誘導が本業**） |
| 設計寿命 | **約300年**（航行期間に相当） |
| 繁殖能力 | **なし**（設計上の制限） |

**大きさの比較**：鎌爪竜（120〜180kg）の3倍以上、ウロジカ（200〜300kg）より大きい。住民の常識では説明できない大型獣として現れる。

### 2-1. 繁殖できない理由と、その物語的意義

管理生物が野で勝手に増えれば生態系管理の意味が失われるため、設計者は必ず繁殖能力を制限する。

**帰結**：**個体数は増えない。減るだけ。**

倒した分だけ世界は確実に、恒久的に良くなる。「倒しても湧いてくる」構造を排除することで、読者のストレスを与えずに達成感を担保する。

## 3\. 信号中継機構——「生きた石柱」

牧夫は頭部後方の器官で、**B番号ノードの信号を受信・増幅・再放射**する。

| 項目 | 仕様 |
| --- | --- |
| 受信 | 最寄りのB番号石柱の信号を拾う |
| 再放射の有効半径 | **約3〜5km**（携行型発振器の80mに対して桁違い） |
| 信号の種類 | 抑制（遠ざける）／誘引（集める）／**統率**（群れを一方向へ動かす） |

### 3-1. 最大の弱点：石柱から離れられない

**牧夫は自前の信号源を持たない。** ノードの信号を中継・増幅しているだけである。

→ **最寄りの石柱から約20〜25km（＝ノードの影響半径）以上離れられない。**

物語上の帰結：

*   **居場所が予測できる**。石柱の位置は広域地図に載っている（前作の遺産）
*   **逃げられる**。影響圏の外へ出れば追ってこない
*   縄張りが石柱に縛られているため、複数体が連合することは原則ない

### 3-2. 主人公の抑制信号が効かない理由

主人公の携行発振器「鈴」（有効半径80m）に対し、牧夫はノード出力を増幅して3〜5kmを覆う。**同じ土俵で競合すれば、出力差で確実に負ける。**

**これが本作の主題である**：主人公は「機能」では敵に勝てない。**装備と訓練の「性能」で勝つ。**

### 3-3. 群れの維持と巡回——餌の収支

**牧夫は定住しない。** 群れを連れて縄張り内を巡回する。これは牧夫本来の職能（家畜の誘導・輪換放牧）そのものである。

| 項目 | 値 |
| --- | --- |
| 信号による群れ制御の半径 | 3〜5km（牧夫自身の周囲） |
| **巡回できる縄張り** | **石柱から半径20〜25km ＝ 1,250〜1,960km²** |
| うち可耕・可猟の面積 | 概ね60% ＝ **750〜1,180km²** |

制御半径（3〜5km）と縄張り（20〜25km）を混同しないこと。**牧夫は群れを連れて縄張り内を移動し続けており、一箇所に留まらない。**

### 3-4. 群れ規模の上限（餌の収支計算）

群れの規模は演出で決めるのではなく、**縄張りの扶養力から算出する**。牧夫は本来「生態系の個体数を局所的に調整する」個体であり、扶養力を超える群れを抱えない（超えた分は間引き・分散させる）。

| 群れ | 頭数 | 必要面積の算出 | 縄張りとの比 |
| --- | --- | --- | --- |
| **草毛獣**（20kg・草食） | 300〜500頭 | 持続的放牧で約0.4ha/頭 → **1.2〜2km²** | **余裕（数百倍）** |
| **針鼠狼**（50kg・肉食） | 40頭 | 捕食者現存量2,000kg → 被食者現存量200t必要。温暖域（約1,500kg/km²）で **約135km²** | 余裕（一号は実効範囲が一桁広い） |
| **鎌爪竜**（150kg・肉食） | 十数頭 | 捕食者現存量2,250kg → 被食者現存量225t必要。寒冷域（約500kg/km²）で **約450km²** | **ぎりぎり（限界に張り付いている）** |
| **水棲種** | 多数 | 水域は生産性が高く、餌が回遊して集まる | 余裕 |

**算出根拠**：肉食獣の現存量は被食者現存量の約1%が生態学的な上限（栄養段階の効率）。草食獣は羊（60kg級で0.5〜2ha/頭）から体重比で換算。

### 3-5. 餌の枯渇が、人里に降りる動機になる

上表の通り、**大型肉食獣を率いる牧夫だけが扶養力の限界に達する**。

> **牧夫が人里に降りてくる理由は、悪意ではなく、縄張りの餌が尽きたからである。**

これにより：

*   4体それぞれに悪意でない動機が与えられる（→8節）
*   放置された3体が脅威にならない理由も説明される（**縄張りにまだ餌がある**）
*   「管理者を失った道具」というトーンが崩れない

### 3-6. 誘引信号の副作用——「獣が消える」という前兆

牧夫は誘引信号で縄張りの外縁から獣を引き込む。外側の個体が空白を埋めるように流入するため、**縄張りの周囲一帯から獣がいなくなる**。

**物語上の使い方**：牧夫が活動を再開した最初の徴候は襲撃ではなく、**静けさ**である。狩人が獲物を見つけられなくなる。

> 「獣が、いません」
> 「いないなら、いいことでは」
> 「よくありません。**どこかに集まっている、ということです**」

襲撃より先に「異常な静けさ」を置くことで、不気味さと調査の手順を両立できる。

### 3-7. 巡回することの物語的帰結

*   **敵の居場所が固定されていない**。追跡と予測が必要になり、感覚拡張と広域地図が活きる
*   **被害が周期的になる**。「あの村は三ヶ月おきに襲われる」という不気味な規則性＝牧夫の巡回周期
*   **先回りできる**。巡回路を読んで待ち伏せる＝準備型の戦闘に持ち込める（前作の血脈）

## 4\. 「知恵」の設定的根拠

**拡散MTMを原因にしてはならない**（→99\_矛盾リスト M019。生物変異の原因はDNA設計＋生態系管理喪失のみ）。

牧夫の知恵は、変異ではなく**設計仕様そのもの**である。

| 設計された形質 | クストス稼働時代 | 管理喪失後 |
| --- | --- | --- |
| 群れの統率能力 | クストスの指示に従って行使 | **自分の目的のために行使** |
| 地形と経路の学習 | 誘導ルートの最適化に使用 | 待ち伏せ・迂回・退路封鎖に使用 |
| 個体の識別 | 家畜の個体管理 | **人間の識別**。同じ相手を覚える |
| 信号の使い分け | 抑制／誘引／統率の切り替え | 同（**用途が変わっただけ**） |

**要点**：牧夫は「獣が知恵をつけた」のではない。**元から群れを管理するために設計された個体が、管理者を失って、群れを自分のために使い始めた**だけである。

新たな能力を獲得していないため、既存設定と一切衝突しない。

## 5\. 休眠と覚醒

### 5-1. なぜ2,000年生きられたか

牧夫は石柱の周辺で**代謝を落とした長期休眠**に入れる（低メンテナンス運用のための設計機能）。信号が途絶えると自動的に休眠へ移行する。

事故後、クストスの停止で信号が失われ、全個体が順次休眠に入った。

### 5-2. 生存率——約5%

| 状態 | 数 | 理由 |
| --- | --- | --- |
| **配備時** | **約990体** | 陸地セル1個（約881km²）に1体（→02「4-2. サブノードのネットワーク」） |
| 死亡 | 約940体 | 休眠移行の失敗、担当ノードの完全停止、休眠中の事故・崩落、覚醒後の餓死 |
| **現存** | **約50体（約5%）** | 休眠に成功し、担当ノードに微弱な信号が残っていた個体 |

### 5-3. 覚醒の引き金——「三本の柱」

辺境拠点日誌 第140話で三ノードが復旧し、二千年ぶりに信号が発生した。この信号は**生き残った標塔リンクを辿って樹状に伝播**した（→99\_矛盾リスト U014。リンク生存率 約5%）。

| 項目 | 値 |
| --- | --- |
| 信号が到達したセル | **約140セル**（全1,692セルの約8%） |
| うち牧夫が休眠していたセル | **7セル**（140 × 生存率5%） |
| **活動を再開した牧夫** | **7体** |

**重要**：**主人公の保存槽も、この経路上の1セルにあった。**

> カイたちが世界を支えた結果、遠く離れた土地で、古い守り手と古い脅威が同時に目を覚ました。

これは皮肉でも悲劇でもなく「世界が動き出した」という事実である。前作の後味を損なわない。

### 5-4. 副産物：主人公の旅路が設定から決まる

信号は**面ではなく線状・樹状に**伝播した。したがって覚醒した7体は、三ツ辻から伸びる**一本の経路上に並んでいる**。

主人公は「信号が通った道」を辿ることになり、その道筋に敵がいる。**旅の順路を作為的に決める必要がない。**

## 6\. 現存50体の地域分布

生存条件は「休眠が破られていない＝人が近づかない」であるため、分布は**人口分布と逆相関**する。

| 地域 | 人口 | 陸地 | **推定生存数** | 生存理由 |
| --- | --- | --- | --- | --- |
| **温暖域** | 7%（20万人） | 55万km² | **約25体** | 03に「大災害前は大都市が集中、現在は廃墟が多い」。人が寄らず休眠が保たれた最良の環境 |
| **寒冷域** | 13%（40万人） | 28万km² | **約15体** | 山がちで到達困難。長い冬 |
| **温帯域** | 80%（240万人） | 66万km² | **約10体** | 主要居住帯。大半が死亡。残存は深山・廃坑・禁域深部に限られる |

**温暖域の廃墟地帯が最大の在庫**になる。TRPGシナリオの舞台としても使いやすい。

## 7\. 活動再開7体の区分

| 区分 | 数 | 内容 |
| --- | --- | --- |
| **正史で討伐** | **4体** | 住民の生活圏に侵入し、実害を出した個体 |
| **正史で記録・放置** | **3体** | 活動再開したが無人地帯にいる。**業務判断として交戦しない** |
| 未確認・休眠継続 | 約43体 | シナリオ用在庫（→10節） |

### 7-1. 「放置する」ことが正しい理由

保安部の任務は**居住区の保全**であり、生物の絶滅ではない。無人地帯の個体は住民に害を与えないため、**記録して放置するのが正しい業務判断**である。

搭載生物は生態系の構成要素であり、殺せば補充できない（→09「ドクトリン」）。

**キャラクター表現としての意義**：倒せるが倒さない。これが主人公を駆除業者ではなく保安要員として成立させる。

> 「あと何体いるんですか」  
> 「記録上は、約五十体です」  
> 「全部倒すんですか」  
> 「いえ。人に害のあるものだけです」  
> 「残りは」  
> 「記録して、置いておきます。それが、仕事です」

### 7-2. 放置された3体（余韻として残す）

| 個体 | 所在 | 状態 |
| --- | --- | --- |
| 記録名のみ | 寒冷域・高山の氷河湖畔 | 群れを持たず単独で徘徊。人里から80km以上 |
| 記録名のみ | 内海の孤島（海の標塔付近） | 水棲種を率いるが、島から出られない |
| 記録名のみ | 禁域深部 | 覚醒したが、区画から出る経路がない |

いずれも一行だけ触れて終える。**「いつ動き出すか分からないものが、今も3体いる」という余韻**が残る。

## 8\. 討伐対象4体の詳細

**設計方針**：4体それぞれに、①異なる地形 ②異なる率いる種 ③異なる統率スタイル ④**異なる攻略装備**を割り当てる。09の装備が1体ずつ順に活きる構成とする。

---

### 第1体：「灰の親（はいのおや）」

| 項目 | 内容 |
| --- | --- |
| 地形 | 温帯域の農地・平野（人里に最も近い） |
| 率いる群れ | **草毛獣 数百頭**（本来の管理対象＝最も原型に近い運用） |
| 統率スタイル | **数で押す。自身は絶対に前に出ず、群れを盾にする** |
| 性格 | 極度に臆病・慎重。**それが2,000年生き延びた理由** |
| **人里に来る動機** | **餌の枯渇ではない。** 農地が縄張りに含まれており、耕作地は野の草地より効率が良い。**より良い牧草地として畑を選んでいる**だけ |
| 主要装備 | **指向性音響制圧装置「喝」**（非致死・面制圧） |

**攻略の鍵**：草毛獣は害獣だが、**毛が繊維素材として住民の収入源**である（前作第1部の伏線）。殺せば住民が損をする。

したがって「群れを殺さずに割り、本体だけを撃つ」ことが要求される。**非致死装備の存在意義が、最初の戦闘で示される。**

**見せ場**：農地を埋め尽くす数百頭の白灰色。個体は弱いが、質量が壁になる。「喝」で面を割り、開いた通路を外骨格で突破し、「静」で本体を撃つ。

**主人公の初陣**として、性能・装備・職業倫理を一度に提示する。

---

### 第2体：「三つ首（みつくび）」

| 項目 | 内容 |
| --- | --- |
| 地形 | 寒冷域の廃坑・山岳（閉所） |
| 率いる群れ | **鎌爪竜 十数頭** |
| 統率スタイル | **戦術連携**。鎌爪竜の「3頭一組」を複数班に編成し、多方向から同時に当てる |
| 性格 | 攻撃的。指揮位置を絶えず移動させ、本体を掴ませない |
| **人里に来る動機** | **餌が尽きた。** 大型肉食獣十数頭は寒冷域の扶養力（約450km²必要／使用可能約500km²）の限界に張り付いており、**縄張り内の獣を食い尽くした**。家畜と人間が次の獲物になる |
| 主要装備 | **保安外骨格「鎧」**（閉所白兵）＋感覚拡張 |

**攻略の鍵**：鎌爪竜の陽動戦術（1頭が引きつけ、他が回り込む）は**全周音響探知の前で成立しない**。「真後ろが死角」という弱点も主人公には存在しない。

さらに鎌爪竜は**高温を嫌う**（既存設定）ため、坑道内の火の壁で進路を制限できる。

**見せ場**：坑道の閉所戦。**外骨格の稼働時間3時間20分がタイマーになる**。時間内に指揮個体を追い詰めなければ、装備を失った状態で群れの中に取り残される。

「性能で圧制」に**制限時間**という緊張を持ち込む回。

---

### 第3体：「濁り（にごり）」

| 項目 | 内容 |
| --- | --- |
| 地形 | 大河の渡渉点／内海の沿岸（水域） |
| 率いる群れ | **小型深淵鰐**＋変異した水棲生物（棘水母・攻撃的甲殻類） |
| 統率スタイル | **待ち伏せと擬態**。自身も泥中に潜む。水中は信号伝達が速く、群れの反応が異様に速い |
| 性格 | 消極的だが執念深い。同じ相手を覚え、待ち続ける |
| **人里に来る動機** | **餌は足りている。** 水域は生産性が高く飢えていない。**渡渉点が待ち伏せに最適だから**そこにいる。人が定期的に通ることを学習し、獲物として認識した |
| 主要装備 | **感覚拡張（振動探知）**＋現地の人々との協働 |

**攻略の鍵**：**水中では外骨格が使えない**（電力・浸水）。主人公の最大装備が封じられる唯一の敵であり、**ピンチ担当**。

小型深淵鰐は川底の石に擬態して「止まると見えない」（既存設定）が、**振動探知には映る**。泥中の本体を特定できる。

決着は装備ではなく**準備**でつける——堰を切って水位を落とし、水から出させる。**現地の人々の手が必要になる回**（前作の血脈を軽く継承）。

**見せ場**：装備が使えない状況で、情報と判断と協力で勝つ。無双の例外回だが、**勝ち方が「性能」の延長にある**ことは崩さない。

### 第4体：「一号（いちごう）」／住民の呼称「群れ主の母」

| 項目 | 内容 |
| --- | --- |
| 地形 | **温暖域の廃墟都市**（大災害前の大都市跡） |
| 率いる群れ | 針鼠狼の大群＋**原種**（居住域に入らないよう設計され、住民が一度も見たことのない上位捕食者） |
| 統率スタイル | **統率の階層化**。信号を中継する副統率個体を作り出しており、**本体を倒しても群れが止まらない** |
| 正体 | **最初期に配備された試作機体**。保安部の記録に残っており、**主人公は目覚めた時点でその名を知っている** |
| **人里に来る動機** | **餌の問題を解決してしまった。** 副統率個体で実効範囲を数千km²に広げたため、扶養力の制約から解放されている。飢えではなく**範囲の拡大そのもの**が脅威であり、放置すれば居住域に到達する |
| 主要装備 | **重電磁投射砲「貫」（1基のみ）＋熱プラズマ焼却器「祓」（残90秒）** |

**攻略の鍵**：副統率個体の存在により、**「石柱から20〜25km」という牧夫共通の行動制限を突破している**。実効支配範囲が他の3体より一桁広い。

したがって「本体を撃つ」だけでは終わらない。副統率個体を先に潰し、実効範囲を縮めてから本体を討つ——**二段構えの攻略**が必要になる。

**切り札を両方使い切る**。大型装備2基をウロジカ2頭で廃墟まで運び込み、設置し、一度きりの機会に賭ける。**「偵察→判断→移送→設置」という前作の構造が、クライマックスで最大の意味を持つ。**

**見せ場**：

*   **原種の初出**。住民が2,000年見たことのなかった上位捕食者
*   廃墟都市という、住民の常識の外にある舞台
*   主人公の記録にある「試作機体」という名が、最終決戦で回収される

## 9\. 群れとの関係——爽快感の型

牧夫1体が率いる群れの規模は、縄張り（石柱から半径20〜25km）の扶養力から決まる（→3-4）。草食獣なら数百頭、大型肉食獣なら十数頭が上限。これが敵の「軍勢」となる。

**「数百頭」を無条件に使い回さないこと。** 肉食獣は栄養段階の制約で二桁少ない。

**基本の型**：

> 群れを性能で蹴散らす → 頭を討つ → **信号が消えて群れが解散する** → その地域が恒久的に解放される

1体の討伐で1地域。数話〜十数話で1体。**なろうの連載構造にそのまま乗る。**

**重要**：群れは牧夫を失えば散るだけで、絶滅させる必要はない。**群れの大半を生かしたまま解決する**ことが、保安部ドクトリンとも住民の利益とも一致する。

## 10\. TRPG・他作品での利用ガイドライン

### 10-1. 自由に使える在庫

| 対象 | 数 | 使い方 |
| --- | --- | --- |
| **未確認・休眠個体** | **約43体** | 任意の地域に配置できる。地域別の推定数（→6節）の範囲内であれば正史と衝突しない |
| **放置された3体** | 3体 | 所在は指定済み。目覚めさせる／接触するシナリオが組める |

### 10-2. 休眠個体を目覚めさせる引き金（シナリオフック）

*   三本の柱の輪番が拡大し、新たなノードに信号が戻る（→前作の「柱が増えれば繋がる経路も増える」）
*   探索者が石柱を操作する／禁域を再起動する
*   落盤・地震・洪水で休眠場所が破られる
*   別の牧夫の信号が届く

### 10-3. 正史に触らないための制約

| 禁止 | 理由 |
| --- | --- |
| 討伐された4体を生存させる | 正史と衝突 |
| 牧夫を繁殖・増殖させる | 設計上の繁殖制限に反する。個体数は減る一方でなければならない |
| 総数を50体より大幅に増やす | 生存率5%の根拠が崩れる |
| 牧夫を「全滅させた」と宣言する | 設定資料としての在庫価値が失われる |
| 石柱から25km以上離れて活動させる | 副統率個体を作った「一号」のみの特性 |

### 10-4. 難易度の目安

牧夫は**現代の技術では正面から倒せない**存在である。

*   隊商の護衛7〜10名では**勝てない**（体重400〜600kg、群れ数百頭を伴う）
*   集落の総力戦で「追い払う」ことは可能。**討伐は困難**
*   古代装備・古代知識・大規模な準備のいずれかが必要

→ TRPGでは「倒す敵」ではなく**「逃げる・避ける・追い払う・原因を突き止める」対象**として扱うのが適切。討伐を目的にする場合は、キャンペーン規模の準備を前提とすること。

## 11\. 執筆時の注意

### 書いてよいこと

*   牧夫が群れを「使う」描写（設計された統率能力の行使）
*   石柱に縛られた行動範囲（予測できる／逃げられる）
*   主人公の抑制信号が**通じない**こと
*   倒した地域が恒久的に解放されること
*   **倒せるが倒さないという業務判断**

### 書いてはいけないこと

| 禁止 | 理由 |
| --- | --- |
| 変異・進化で知恵を得たとする | **M019違反**。設計仕様に元からあった形質 |
| 拡散MTMを原因にする | **M019違反** |
| 繁殖・増殖させる | 設計上の繁殖制限 |
| 石柱から遠く離れて活動させる | 信号中継機構の前提が崩れる（「一号」を除く） |
| 人語を解する／会話する | 管理生物であり、知性化した存在ではない |
| 複数体が連合する | 縄張りが石柱に縛られているため原則不可 |
| 全個体を討伐する | 正史では4体のみ。**約43体を在庫として残す** |

### 描写のトーン

牧夫は悪意を持った敵ではなく、**管理者を失った道具**である。憎悪の対象としてではなく「片付けるべき問題」として描くと、後味が軽くなり読者のストレスが減る。

ただし主人公は感傷を表に出さない。**業務として処理する**姿勢を貫くことで、かえって重さが出る。
