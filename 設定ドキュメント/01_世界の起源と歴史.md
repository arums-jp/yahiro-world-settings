## 1. 旧地球文明（Type II文明）

### 文明レベルと規模

旧地球文明は「カルダシェフ・スケール」でいうType IIに到達、または接近した文明である。太陽エネルギーの大規模利用、惑星工学（プラネタリー・エンジニアリング）が可能なレベルで、木星のような巨大惑星を解体できるほどの技術力を持っていた。

**時代背景**：
- 22〜25世紀頃、太陽系人口が急増し地球・火星・月・軌道コロニーで合計150億人に達した
- 資源の枯渇懸念、太陽の長期的寿命、「新天地」への探求心が移民計画の動機となった
- 人類の分散によるリスク回避、遺伝的・文化的多様性の保存も目的に含まれる

### ユピテル・プロジェクト（木星解体）

木星（固体核：地球の10〜20倍の質量、直径約14万km）を解体し、複数の移民星を建造する人類史上最大の工学事業。「ユピテル・プロジェクト」と呼ばれ、太陽系移民評議会（Sol System Migration Council）が統括した。

**プロジェクトの工程**（総期間1300年）：
1. 第1段階：木星外層ガス採取（水素・ヘリウム、200年）
2. 第2段階：金属水素層採掘（300年）
3. 第3段階：固体核露出と採掘（鉄・ニッケル等、200年）
4. 第4段階：木星軌道を建造ドックとして移民船を同時建造（500年）

**建造された移民船の数**：
- 木星資材から：約80〜120隻
- 土星資材（後期）から：約40〜60隻
- その他資材から：約20隻
- 合計：約150〜200隻

**現在の木星の状態**（物語時点）：直径約2〜3万kmの岩石惑星の核のみ残存。地球から見ると小さな灰色の点として見える。

### 移民船の分類

| サイズ | 外殻半径 | 収容人口（設計値） | 隻数 |
|-------|---------|----------------|----|
| 大型 | 300〜400km | 1000〜2000万人 | 約20隻 |
| 中型 | 200〜300km | 500〜1000万人 | 約60隻 |
| 小型 | 100〜200km | 100〜500万人 | 約80隻 |

ヤヒロは中型船クラス（外殻半径約510km ※要確認）。

**主な移民星（文化圏別）**：
- ヤヒロ：日本文化圏
- フロディアス：ヨーロッパ（アメリカ）文化圏
- クァンロン：中華文化圏
- インダス：南アジア文化圏
- アフリカーナ：アフリカ文化圏
- アメリカス：南北アメリカ文化圏
- その他多数

## 2. ヤヒロの建造

### 建造経緯

**建造場所**：木星軌道上のドック17番
**建造期間**：約350年（設計・準備50年、本体建造150年、内装・環境整備100年、テスト・調整50年）

**建造目的**：日本文化圏の人々を別の恒星系へ移送し、数億年後の地球帰還または新天地での定住を目的とする移民星。日本列島の環境（温帯気候、四季、山地と平野の組み合わせ）を模倣した居住空間として設計された。

**使用資材**：
- 木星固体核：鉄・ニッケル・重金属（球殻の主材料）
- 木星大気：水素・ヘリウム（核融合燃料）
- 小惑星帯：補助的な資材
- 地球から：種子・生物サンプル・文化財・日本語資料・DNA設計情報

**設計思想**：
- 「持続可能な閉鎖生態系」
- 「伝統と革新の調和」
- 「自然との共生」
- 数千年の世代間航行を想定した自律運用設計

### 航行計画

**目標星系**：りゅうこつ座イータ星系（仮称、約300光年）
**航行速度**：光速の99.9988%
**主観時間**：約15年（世代航海で数十世代が船内で生まれ育つ）
**外部時間**：約300年

### 移民の経緯と初期人口

**出発時の乗員**：約1000万人（設計値の50〜75%）
- 主に日本文化圏からの移民
- 一部は他文化圏からの希望者
- 遺伝的多様性を確保するために選別

**移住の動機**：人口爆発・資源枯渇への対応、新天地への探求、人類のリスク分散、日本文化の保存と継承。

**航行中の生活**：高度な技術文明、都市型居住、完全管理下の生態系。数十世代が船内で生まれ育ち、「地球」は伝説となり「目的地の星」が希望となっていた。

### 事故前の生活水準（2000年前まで）

ヤヒロは「日本文化の保存」を設計思想に持つため、技術的に高度であっても生活様式は**現代日本相当**を基本としていた。

- 日常生活：農業・漁業・手工業・商業が普通に営まれる日本的な暮らし
- インフラ：電力・水・気候・重力はクストスが完全管理し、住民は意識せずに享受
- 交通：ヤヒロ内部の輸送システム（詳細未設定）が稼働。艦載小型艇も運用中
- 建築：木造・石造・コンクリート造など現代日本に近い建物
- 高度な技術は「あるが見えない」——ピラーや船体はそこにあるだけで住民は仕組みを知らない

**遺物として残っているもの（2000年後の現在）**：

| 素材・種別 | 残存状態 |
|---|---|
| 木造・紙製の建物・家具 | ほぼ消滅、土に還っている |
| コンクリート・石造りの建物 | 骨格は残るが風化・崩壊 |
| 通常金属製品 | 錆びて朽ちている |
| MTMアロイ製の構造物 | 完全原形保存（劣化ゼロ） |
| 電子機器・精密機械 | 動かないが形は残るものも |
| 道路・舗装 | 自然に侵食されて消えかけ |

住民からは「廃墟の中になぜか完全に綺麗なまま残っている構造物」として神代の遺物として畏敬される。調査隊の視点では「2000年前まで現代日本相当の生活が営まれていた証拠」として読み取れる。

## 3. クストス消失事故（内部時間で約2000年前）

### 事故の概要

ヤヒロが目的地恒星系に接近し、亜光速から減速を開始した際に発生した。管理AI「クストス（Custos）」と主制御システムを喪失し、船は恒星周回軌道から離脱して宇宙空間で「静止」した。

**事故の連鎖**：
1. 目的地恒星系到達、減速開始。ラプラスエンジンへの制御負荷が最大化
2. クストスの量子コアで量子デコヒーレンス発生（宇宙線または時空異常が原因と推定）
3. MTM制御アルゴリズムに0.003秒のズレ→ピラー#1047が設計限界を0.2%超過
4. 異常が0.8秒でネットワーク全体に波及→ラプラスエンジンが制御を喪失
5. 制御を失ったラプラス・ヴェール（進行方向に展開していた面状の航行シールド）が球体に拡張・固定化
6. 37秒かけて境界が完成→これが現在の「因果の泡」
7. クストスは量子コアの量子デコヒーレンスで破損・停止

**結果**：
- クストス（統括AI）およびラプラスエンジン（MTM制御サブシステム）の喪失
- 因果の泡の形成（時空の閉鎖、外部との因果律断絶）
- 時間流の加速（内部：外部 = 10:1）
- 予備系「セカンド」の自動切り替え不発（診断システムが「ハードウェア正常」と判断したため、または因果の泡形成が早すぎたため）

### 事故直後の混乱

- システムの大部分が機能停止
- 通信網の崩壊、都市型居住の放棄
- 生存率は推定27%（約1500万人→約400万人）
- 集落型生活への移行開始
- クストス・ラプラスエンジンなしでは高度技術の維持困難で記録メディアも劣化
- 教育システムの崩壊、口伝文化への回帰

### 搭載艇の墜落

事故の際、一部の搭載艇（短距離シャトル）が地表に墜落した。現在3箇所の墜落地点が確認されている。

**墜落艇1「森の端の銀船」**：
- 集落「森の端」から約2km。半壊だが銀色の外殻は残存
- 静的MTM 150kg残存（密閉維持）
- 現地民の認識：「神代の船の遺跡」として伝承。集落の禁忌（立ち入り禁止）

**墜落艇2「平原の残骸」**：
- 辺境の平原（集落から約50km）。完全破壊、残骸のみ
- 静的MTM約10〜20kg残存
- ほとんど知られていない

**墜落艇3「湖底の探査艇」**：
- 大きな湖の底（水深80m）。船体は水圧で圧壊だが内部は密閉
- 静的MTM 800kg残存（回収には潜水装置が必要）
- 漁師の間で「湖底の光る物体」という噂

## 4. 事故後2000年の歴史概略

### 暗黒時代（事故後0〜150年）

- 通信網・輸送システムの全滅
- 技術文明の崩壊、都市の放棄
- 人口は最低点まで下落（約120万人）
- 食料・水・基本物資の確保のために各地で小集団が形成
- 生存者は地表層の農業ポテンシャルを発見し始める

### 再建期（150〜500年）

- 集落システムの形成：自給自足可能な小規模集団が各地に定着
- 特化型産業の発達（農業集落・製塩集落・鉱業集落など）
- 隊商交易システムの確立（集落間の相互依存を生む）
- 文字は一部のみ（語り部・記録係）、口伝文化が主流
- 「古代人」の伝説化、「失われた技術」の神格化

### 安定期（500〜1800年）

- 集落システムの成熟と安定
- 隊商ネットワークの発展（交易路の確立）
- 人口の緩やかな回復（約200万人→約270万人）
- 生態系の急激な変化（DNA設計による高い適応速度と、生態系管理喪失による自然選択の加速）
- 「古い記録にない生物」の出現が常態化

### 現在（事故後約2000年）

**物語の現在時点**：
- 総人口：約300万人
- 集落数：約6,900
- 平均集落人口：400〜500人（平均435人）
- 技術レベル：中世〜近世相当
- 平均寿命：約90歳
- 静的MTM残存量：約33%（残り約1000年で枯渇）

**外部の時間軸**：
- ヤヒロ内部で2000年経過 = 外部宇宙では約200年経過（時間流10倍の差）
- 外部時間で約200年前（ヤヒロ内部時間で約2000年前）に事故発生
- 外部時間で約1年前（内部時間で約15年前）に調査隊が侵入

## 5. 「因果の泡」の発生と現在の孤立状態

### 因果の泡とは（住民の認識）

住民たちは「因果の泡」の存在を知らない。彼らが持つ認識は以下の通り：

- 「祖先の時代に世界が止まった」という語り部の伝承
- 外の世界との連絡手段がない（当然のこととして受け止めている）
- 「世界の果て」に行った者の伝説はあるが、誰も到達していない
- 外の世界があるかどうかすら、多くの住民は考えない

### 伝承が2000年を経て残っている理由

事故直後に生き残った第一世代が、失われゆく記憶を守るために語り部という職能を強化した。「星の海を渡った祖先」「動く星の時代」「母なる星・地球」などの物語は、航行中から存在した語り部の伝統に組み込まれ、世代を超えて語り継がれた。

2000年の口伝を経て内容は神話化・変容しているが、核となる事実（「かつて星は動いていた」「祖先は星の海を渡ってきた」「大きな災害があった」）は残っている。これは現実の地球でも2000年前の出来事が伝承・神話として残っていることと同様のメカニズム。

語り部同士のネットワークが伝承の整合性を一定程度保ち、意図的な「伝承の管理」が行われてきた。

### 因果の泡の実態（作者・調査隊視点）

事故により、ヤヒロ全体が「因果の泡」と呼ばれる時空の閉じた系に封じ込められた。

- 境界：直径約1,100km（ヤヒロ本体半径450km＋安全マージン約100km）の球殻
- 内部時間：外部時間の10倍速
- 外部からの侵入：可能（制御された「下り坂」）
- 内部からの脱出：原理的に不可能（時間の矢への逆行）
- 外部からの観測：「真っ黒な球体」として見える（電磁波を吸収する完全黒体）
- 重力波：約24時間周期（内部時間）で微弱な重力波を放出（外部から観測可能）

**孤立状態の現実**：
- 内部→外部への通信：完全に不可能
- 外部→内部への通信：理論上可能だが実用困難（時間圧縮でデコード不能）
- 調査隊15名は母船とも通信不可能（完全孤立）

## 7. 調査隊と外部からの接触

### フロディアスからの調査隊派遣

ヤヒロと同型の移民星「フロディアス」（アメリカ・ヨーロッパ文化圏ベース）の管理AI「ヤヌス」が、ヤヒロの異常を感知した。フロディアスは亜光速航行を継続しているため、ウラシマ効果によりヤヒロ内部の2000年に対してフロディアス側は数十年しか経過していない。

**調査隊の概要**：
- 25名で構成、調査船「レインボーファルコン」で出発
- フロディアス出発から侵入まで：コールドスリープ含む主観時間約3年（航行1年、準備2年）
- 因果の泡侵入時：防空システム「カグツチ」の妨害を受け10名が死亡
- 現在：15名が地表で活動（内部時間で約15年前に侵入）

**母船「レインボーファルコン」**：
- ヤヒロの因果の泡境界外側に停泊
- 乗組員約20名（技術要員・医療要員・予備調査員）が待機
- 因果の泡内部とは通信不可能
- フロディアスとも実用的な通信不可能（距離と時間差のため）

**調査隊の派遣目的（多層的）**：
1. 表向き：救援・事故調査
2. 科学的：史上初の因果の泡内部観測データ取得
3. 軍事的：内部脱出技術の開発
4. 危機管理：MTM技術の危険性検証
5. 全隊員が片道切符の可能性を承知の上で志願

**現在の調査隊の状況**：
- 「帰還派」（5名）・「共生派」（6名）・「救済派」（4名）の3グループに分かれて活動
- 3ヶ月に1度の全体会合で対話継続
- 母船・フロディアスとも完全に通信不可能で絶対的孤立状態
