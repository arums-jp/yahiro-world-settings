# ヤヒロ世界：隊商システム

────────────────────────────────────────

## 1. 隊商の役割と種類

### 隊商の本質的な役割

隊商は単なる物資の運搬業者ではなく、ヤヒロ社会を繋ぐ生命線である。

**物資の輸送**：塩・金属・繊維・薬草・食料など、各集落が自給できない必需品の流通を担う。

**情報の伝達**：唯一の集落間コミュニケーション手段。遠い集落の噂・新しい技術・危険生物の情報・市場の相場を運ぶ。情報は商品と同等以上の価値を持つ。

**血の多様性の維持**：
- 集落外への移住を希望する若者を護送する
- 引退した隊員を新天地（集落）に定住させる
- 縁談を仲介する
- 外部から新しい「血」をもたらし、閉鎖集落の近親交配を防ぐ
- 2000年間にわたって遺伝的多様性を保つ役割を果たしてきた

**技術・文化の伝播**：各地の技術情報・新種の種子・文化的産物を各地に運ぶ。

### 隊商の種類（規模別）

**小規模隊商（8〜15人）**：
- 馬10〜18頭、荷車2〜4台
- 運搬商品価値：小麦換算で2,500〜4,000kg相当
- 1集落あたり利益：750〜1,250kg相当
- 巡回範囲：半径100km、訪問集落数10〜15、周期約120日（4ヶ月）
- 小規模集落間の交易、機動力が必要な地域に向いている

**中規模隊商（20〜30人）**：
- 馬25〜40頭、荷車6〜10台
- 運搬商品価値：小麦換算で7,500〜12,500kg相当
- 1集落あたり利益：1,500〜3,000穀
- 巡回範囲：半径200km、訪問集落数20〜30、周期約240日（8ヶ月）
- 最も一般的な規模。コスト・安全性・利益のバランスが最良

**大規模隊商（40人以上）**：
- 馬60頭以上、荷車15台以上
- 運搬商品価値：小麦換算で25,000kg相当以上
- 1集落あたり利益：5,000kg相当以上
- 巡回範囲：半径300km、訪問集落数40〜50、周期約360日（1年）
- 維持コストが高く、大規模集落間でなければ採算が取れない

**訪問頻度の注意点**：1つの隊商が特定の集落を訪問するのは年間2〜3回程度（巡回ルートの都合）。「年間10〜15回の訪問」は複数の異なる隊商の累計。

## 2. 典型的な隊商の構成

### 人員と役割

| 役割 | 人数（中規模） | 主な担務 |
|-----|------------|--------|
| 隊長 | 1 | 全体の指揮・経路判断・集落長との交渉 |
| 副隊長 | 1 | 馬の健康管理・出発準備・隊の状態確認 |
| 交易担当（商人） | 2〜3 | 価格交渉・商品知識・帳簿管理 |
| 護衛 | 7〜10 | 武装した戦闘員（隊の1/3程度）、危険生物対処 |
| 斥候 | 2 | 先行偵察・狩猟担当（兼任が多い） |
| 御者 | 6〜10 | 荷車の操縦・積み下ろし |
| 軍医・薬師 | 1 | 人員と馬の医療 |
| 料理人 | 1 | 食事の準備・食料管理 |
| 修理工 | 1〜2 | 荷車・道具の修理 |

隊員の多くは複数の役割を兼任する。護衛が斥候を兼ねたり、御者が修理工を兼ねたりする。

## 3. 荷車の仕様と積載

### 基本仕様

**形式**：四輪荷車（不整地での安定性を重視）
**全長**：約4メートル
**全幅**：約2.5メートル（荷台床面積8〜10m²）
**荷台の高さ**：地上から0.8〜1メートル

**重量**：
- 空荷時：約200〜250kg
- 最大積載量：500〜800kg
- 満載時の総重量：700〜1,050kg

**牽引**：2〜4頭の牛または馬（地形により編成変更）

### 素材と構造

金属が希少なこの世界では骨甲・植物繊維を多用：

**フレーム**：
- 主材：硬質な巨木（乾燥・削り加工）
- 補強：大型獣の骨（接合部・荷台支柱）
- 接合：骨甲製の釘・蔓製のロープ・植物性接着剤

**車輪**：
- タイヤ部：大型獣の骨甲（磨り減りにくく弾力あり）
- スポーク：中型獣の骨（軽く強い）
- ハブ：最も負荷がかかる部分。骨製ハブ＋銅製軸受け（最良）または骨甲ハブのみ（廉価版）

**積載部**：
- 床板：硬質木材（反りにくく耐湿）
- 側板：着脱可能な骨甲板
- 屋根：防水処理済みの植物繊維布（帆布相当）

**重要部品の消耗**：
- 車軸と軸受け：最も消耗が早い。骨製軸受けは20日間の旅で2〜3回の調整が必要。銅製軸受けは耐久性が高い
- ルート選択の重要な判断基準のひとつが「車軸への負荷」

### 積み荷の管理

- 重い荷物は中央・下部に配置（重心を低く安定させる）
- 防水対策が必須（雨季・渡渉時）
- 帳簿担当が積み荷の内容・重量・価値を記録

## 4. ルート選択の考え方と判断基準

### 基本方針

「道のない不整地を、できるだけ高低差を避け、森を迂回しながら進む」。固定した道路はなく、毎回の旅で経路を判断しながら進む。

### 判断基準（優先順位）

1. **車軸の損傷リスク**：急な高低差・岩石地帯は車軸への負荷が大きい。車軸を失えば旅が終わる。
2. **危険生物との遭遇リスク**：密林・草むら・日没後は危険。安全な巻き道を選ぶ。
3. **水源の確保**：馬・人員に必要な水が途中で確保できるか。
4. **日程遅れによる交易機会の損失**：遅延は次の集落での滞在時間を減らす。
5. **天候・季節**：嵐の季節・増水期は迂回が必要。

### 移動速度の目安

| 地形 | 1日の移動距離 |
|-----|-----------|
| 平坦な草原・平原 | 15〜20km/日 |
| 丘陵地・軽い森林 | 10〜15km/日 |
| 険しい地形・密林 | 5〜10km/日 |

**標準的な中規模隊商**：平均10km/日、週1日程度の休息。迂回率1.3〜1.5倍を考慮すると、集落間の直線距離60〜70kmを9〜10日で移動。

## 5. 一日の行動スケジュール

### 移動の日（一例）

| 時刻 | 行動 |
|-----|-----|
| 06:00 | 隊長が周囲確認。夜の警戒番を労って引き上げ。馬の足並み確認を指示 |
| 07:00 | 一行が起床。副隊長が馬の脚・健康状態を確認 |
| 08:00 | 簡素な朝食（黒パン・乾燥果実・塩漬け肉を少量） |
| 08:30 | 出発準備。隊形を整え（前衛護衛→商人・使用人→荷馬車→後衛護衛）、号令で出発 |
| 10:00 | 定期的に馬の呼吸・歩様を確認。地形に応じて経路を都度判断 |
| 12:00 | 水源（沢・池）で昼の休息。馬に水を飲ませる。焚き火は煙で獣を呼ぶため控えめ |
| 14:00 | 午後の移動再開 |
| 16:00 | 夜営地の候補を探し始める（岩盤脇・見晴らしの良い場所等） |
| 18:00 | 野営地設営開始。荊棘柵を張り、焚き火の場所を確保。馬を窪地に誘導 |
| 19:00 | 夕食（乾燥野菜・豆・塩漬け肉の煮込み）。本日の進行状況を帳簿に記録 |
| 20:00 | 夜間警戒当番を決定。5人が4時間ずつ交代 |
| 21:00〜 | 残りの隊員は就寝。松明の明かりが獣への抑止力になる |

### 集落での営業日（一例）

| 時刻 | 行動 |
|-----|-----|
| 06:00 | 隊長が集落の長老との前日の商談を確認 |
| 07:00 | 中央広場の仮設テントで商品の陳列・価格設定 |
| 08:00 | 朝市開始。骨甲工芸品・水晶砂等の販売。若い隊員が集落内の交易情報を収集 |
| 11:00 | 午前の営業に一区切り。馬の本格的な治療・休息 |
| 12:00 | 集落の共同食堂で昼食（地元の家庭の味） |
| 13:00〜 | 午後の営業（職人・労働者が戻ってくる時間帯） |
| 18:00 | 営業終了。当日の決算（売上・市場税差し引きの純利益を計算） |
| 19:00 | 集落の宿屋に宿泊（8部屋程度）。宿の女主人から周辺の情報を収集 |
| 21:00 | 商人が帳簿と相談しながら今後3ヶ月の営業計画を作成 |

## 6. 野営地の設営と安全管理

### 野営地の選定基準

- 岩盤や大石の側（三方を守れる）
- 高低差があり見通しが良い
- 水源が近い
- 草が少ない（獣が潜みにくい）

### 荊棘柵（けいきょくさく）

**材料**：棘のある灌木の枝を束ねたもの
**設置方法**：野営地を囲むように展開
**効果**：小〜中型の危険生物を近づけにくくする。大型には効果が薄い
**設置時間**：30〜60分（慣れた隊員で）

### 警戒体制

- 夜間は交代制で常に見張りを配置
- 5人が4時間ずつ交代（一晩で全員が一度は担当）
- 松明の明かりは「存在感」を示すことで獣を遠ざける効果がある
- 焚き火を絶やさない（光と熱が抑止力）

### 緊急時の対応

- 危険生物が接近した場合：嫌音鈴の使用、集団での追い払い
- 重傷者発生：軍医が処置。重篤な場合は最寄りの集落へ急行
- 荷車の故障：修理工が対応。修理不能の場合は積み荷を他の荷車に移載

## 7. 食料管理（保存食・狩猟・採集・集落での調達）

### 食料の基本方針

隊商は通常20日分の保存食料と十分な安全マージンを持って旅をする。食料不足で困窮することは通常ない（隊商はプロの商人）。

**保存食の内容**：
- 乾燥穀物・豆類
- 乾燥果実
- 塩漬け肉（隊商は常に塩を多く携帯）
- 硬いパン（黒パン等）
- 燻製魚・干し魚

### 狩猟・採集による補充

**斥候による狩猟**：
- 山鳥・小動物を移動中に狩る（斥候が兼任することが多い）
- 果実・野草の採集（食用と薬草を兼ねて）
- 目的：保存食の節約と食事の質向上

**具体例**：
- 前方偵察中に山鳥を仕留める（夕食の主菜に）
- 沢沿いで薬草・山菜を採集
- 集落近くの果樹から果実を採集（許可を得た上で）

**注意**：危険生物が多いため、単独行動・深い森への採集は避ける。複数人で行動。

### 集落での調達

集落への到着時に：
- 新鮮な食料（川魚・野菜・乳製品等）を購入または贈与で入手
- 集落の共同食堂を利用
- 市場での仕入れ（次の区間の食料確保）

### 食事の内容（移動中）

朝食（簡素）：黒パン・乾燥果実・昨日の残り汁・水
昼食（簡素）：携行食（乾燥穀物・塩漬け肉）、焚き火せず
夕食（主食）：乾燥野菜・豆・塩漬け肉の煮込み。狩猟があれば新鮮な肉

## 8. 交易の流れ（集落到着から出発まで）

### 到着・交渉

1. **集落への接近**：標準的には見張り台から発見され、集落の「出迎え役」が応対
2. **許可の取得**：隊長が長老（または集落長）と交渉し、滞在日数・市場使用料・宿泊料を決定
3. **市場区画の確保**：中央広場の一角に仮設テントを設営
4. **市場税**：通常は取引額の10%。ただし歓迎のため免税されることもある

### 商いの流れ

5. **商品陳列・値付け**：各商品に価格を設定（産地で安く、遠地で高く）
6. **営業**：朝市（地元住民が集まる）と昼以降（職人・労働者が戻る）の2つのピーク
7. **情報収集**：若い隊員が集落住民から情報を聞き出す（需要・相場・近隣集落の状況）
8. **仕入れ**：集落の特産品・必要な物資を購入（次の集落への転売品）

### 決算と出発

9. **毎日の決算**：商人が帳簿に記録（売上・費用・純利益）
10. **滞在期間終了**：予定通り（通常2〜5日）または延長申請
11. **出発**：馬の健康状態・積み荷の確認後、次の集落に向けて出発

### 標準的な収益

中規模隊商の場合：
- 1集落での1日の売上：350穀（普通日）〜700穀（良い日）
- 市場税（10%）差し引き後の純利益：315〜630穀/日
- 5日間の滞在で：1,500〜3,000穀の純利益が目標

## 9. 護衛と危険への対処

### 護衛の役割

隊の約1/3を護衛が担う（中規模20人なら7〜10人）。

**危険生物対処**：
- 斥候が先行して危険生物の痕跡（足跡・糞・食痕）を確認
- 発見時は号令で隊が集団行動に移行
- 集団の圧力で追い払う（危険生物は単独よりも集団を避ける）
- やむを得ない場合は撃退

**対盗賊**（稀だが存在）：
- 小規模隊商は護衛が手薄で狙われやすい
- 交渉・威嚇が基本。戦闘は最終手段

### 危機後の変化

危機（危険生物の侵入）以降、護衛の規模が増強：
- 危機前：護衛2〜3人
- 危機後：護衛4〜6人（中規模隊商）
- 運賃の値上げ（10〜20%）

### 危険生物への対応ツール

- 嫌音鈴：特定周波数の音で肉食獣を遠ざける
- マスキング・オイル：匂いを消す軟膏
- デコイ・バッグ：囮袋（逃走用）
- 松明・焚き火：夜間の抑止力

## 10. 隊商の社会的地位・慣習・文化

### 集落における地位

隊商は危険な旅をして希少な物資と情報を運ぶ「命がけの使者」として、訪問先の集落から歓迎される。

**歓迎の慣習**：
- 無償の宿泊・食事・土産（小麦換算で10〜40kg相当）の提供
- 広場での市場の確保
- 護衛のための休憩所の提供

**情報の価値**：集落住民にとって、隊商が持ち込む外の世界の情報は最大の娯楽・関心事。商品と同様に情報も交換される。

### 内部の慣習

**責任の明確化**：
- 隊長の指示が最優先
- 特定の判断（馬の健康・経路変更）は専門担当が権限を持つ
- 集団行動・相互扶助が基本

**隊員の定着・離脱**：
- 旅の途中で集落に定住したい隊員は、隊の負担にならないよう建材・食料・道具を贈与してから「引退」する
- 定住した元隊員は「旅の知識」を持つ貴重な人材として集落に歓迎される
- 逆に「外の世界を見たい」若者が隊員として登用されることも多い

**内部の人間関係**：
- 長期間（数ヶ月）を同じ旅仲間として過ごすため、信頼関係と上下関係が明確
- 厳しい旅の中での助け合いが隊の絆を生む
- 隊員同士の婚姻も珍しくない

### 中継所の利用

**中継所**：主要交易路上に平均50〜100km間隔で配置された施設
- 宿舎（20〜50人収容）・厩舎・倉庫・井戸・炊事場・防護柵・見張り台
- 管理人（家族で運営）が隊商からの利用料で生計を立てる
- 危険な野営よりも安全で快適（有料）
