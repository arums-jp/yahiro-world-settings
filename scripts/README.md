# ヤヒロ世界設定 検証ツール

プロジェクト内の矛盾検証を支援するツール群です。

## スクリプト一覧

### 1. `check-consistency.py` - 整合性チェック（推奨）

ヤヒロ世界設定全体の矛盾・曖昧点・要確認マーカーを一括検出します。

**実行:**
```bash
python3 scripts/check-consistency.py
```

**出力:**
- 矛盾リスト（M001-M007）：既知の矛盾
- 曖昧・未定義リスト（U001-U008）：詳細が未定義の項目
- 数値パラメータチェック：複数ファイルで異なる値を検出
- 要確認マーカー：ファイル内の「※要確認」を検索

**活用シーン:**
- プロジェクト開始時
- 新規設定を追加した後
- 矛盾を修正した後の確認

### 2. `add-contradiction.py` - 矛盾の記録

新しく見つかった矛盾を `99_矛盾・未解決事項リスト.md` に追加します。

**実行:**
```bash
python3 scripts/add-contradiction.py M008 "新しい矛盾" \
  "ファイルA.md" "記述内容A" \
  "ファイルB.md" "記述内容B"
```

**パラメータ:**
- `code`: 矛盾コード（M008, M009など）
- `title`: 矛盾のタイトル
- `file_a`, `detail_a`: ファイルA の情報
- `file_b`, `detail_b`: ファイルB の情報

**出力:**
矛盾リストファイルを更新し、最終更新日時を自動更新

## 使い方ガイド

### 新規設定追加時のワークフロー

1. **整合性チェック**を実行
   ```bash
   python3 scripts/check-consistency.py
   ```

2. 新規設定ファイルを追加・編集

3. **再度整合性チェック**
   ```bash
   python3 scripts/check-consistency.py
   ```

4. 新しい矛盾が見つかった場合、記録
   ```bash
   python3 scripts/add-contradiction.py ...
   ```

5. CLAUDE.md の「優先解決順位」を参照して対処

### 矛盾を解決した時

1. `99_矛盾・未解決事項リスト.md` 内の該当矛盾を「解決済」に変更

2. 関連ファイルを修正して値を統一

3. 整合性チェックを実行して確認
   ```bash
   python3 scripts/check-consistency.py
   ```

## ファイル構造

```
scripts/
├── check-consistency.py    # 整合性チェック
├── add-contradiction.py    # 矛盾記録
└── README.md              # このファイル

設定ドキュメント/
├── 01_世界の起源と歴史.md
├── 02_世界構造と物理.md
├── ...
├── 08_作者専用・裏設定.md
└── 99_矛盾・未解決事項リスト.md ← 検証対象
```

## 矛盾コード

- **M001-M007**: 実在する矛盾（解決待ち）
- **M008以降**: 新しく追加された矛盾
- **U001-U008**: 曖昧・未定義項目
- **C001-C002**: 独自単位に関する注記

## 設定値の主要パラメータ

整合性チェックで監視される主要数値：

| パラメータ | 説明 | 単位 |
|-----------|------|------|
| 外殻半径 | ヤヒロの最外殻 | km |
| 地表半径 | 居住可能な表面 | km |
| 人工太陽軌道 | 照明システムの軌道 | km |
| MTM残存量 | エネルギー物質の残存 | % または kg |

## トラブルシューティング

**スクリプトが実行できない場合**

Python 3 がインストールされているか確認：
```bash
python3 --version
```

**矛盾リストが見つからないエラー**

`設定ドキュメント/99_矛盾・未解決事項リスト.md` が存在するか確認

**文字化けが発生する場合**

Windows の cmd.exe の場合、以下で UTF-8 に設定：
```bash
chcp 65001
```
