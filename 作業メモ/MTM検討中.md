最終更新：2026-03-28

## 現在の設定（確定済み）

- **MTM**（メタ・タキオン・マテリアル）：実態は場や現象だが、仮想的な物質として扱う概念。「こういう効果を示す何かをMTMと呼ぶ」という実用主義的定義。旧文明の科学者自身も完全には本質を理解していない。
- **静的MTM**：MTMアロイにMTMが記録された状態。亜光速航行中かつラプラスエンジン稼働中のみ記録可能。現在は枯渇資源（残存約20%、年間約0.02%消費、約1000年で枯渇。外部時間換算で約100年）
- **動的MTM**：静的MTMが閾値以上の熱エネルギーで励起された活性状態（励起にはラプラスエンジン不要）。局所的に「あり得たはずの時空」が重ね合わせ状態で存在し、核融合を10⁶倍加速、重力場を10³倍効率化。使用後は不可逆的に拡散MTMへ
- **拡散MTM**：使用済みの動的MTM。重ね合わせが収束した残滓。大気・水・土壌に浸透。因果の泡内では還元経路が遮断されて蓄積。**動植物への影響はない**（動植物の急速進化はDNA設計によるもの）
- **MTMアロイ**：MTMを「記録」するための器となれる特殊な結晶構造を持つ合金。記録量は質量に比例。MTMが抜けた後は空のMTMアロイとして再利用可能（MTMアロイ自体は消耗しない）
- **サンドクリスタル**：MTMアロイを砂粒状（0.1〜0.5mm）に加工したもの。励起の閾値が低く扱いやすい。エネルギー資源として運用するための形態

## 決定事項

### 【A】MTMの本質
- 実態は**場や現象**だが、**仮想的な物質として扱う概念**
- ヤヒロ住民にはMTMの**存在自体が未知**（概念として存在しない）
- 知っている存在：コールドスリープ中の技術者、フロディアスからの調査隊メンバー、物語の都合で追加可能

### 【B】静的MTMの生成条件
- 亜光速航行中の時空歪み＋ラプラスエンジンの演算によって**MTMアロイにMTMが記録**される
- 「本来起こるはずだった物理現象のエネルギー」が行き場を失い、MTMアロイの結晶格子に固着
- 生成には**亜光速航行とラプラスエンジンの稼働の両方**が必要条件
- 現在のヤヒロでは両方失われているため**補充は完全に不可能**

### 【C】拡散MTMの動植物への影響
- **影響なし**
- ヤヒロの動植物の急速な進化・変異はDNAレベルで「成長・世代交代が速い」よう設計されていたことによる

### 【D】MTMアロイの定義（大幅更新）

**2種類の用途・構造**：

| | 構造材用（第1層・ピラー・第5層） | 貯蔵用（第6層） |
|---|---|---|
| 形状 | 幾何学的に1つの連続した構造体 | 粒体・粉体の集積体 |
| MTM消費 | 少しずつの消費は不可（全体が一体） | 粒単位で独立→少しずつ励起・消費可能 |
| 用途 | 船体骨格・装甲・シールド | エネルギーバッテリー |

第1層・ピラー・第5層は物理的に**第6層と分離**している。

**MTM記録済み状態の2つの重要な性質**：
1. **破壊不可能性**：閾値未満のエネルギーは構造体全体に時間を超越して瞬時分散。外殻へのミサイル着弾・酸による腐食も無効
2. **MTM伝達性**：励起されたMTMの事象を構造体を通じて伝達。第6層→ピラー→天体層（人工太陽）への輸送の根拠

**空のMTMアロイの性質**：
- 通常の金属と同程度の強度・耐食性に戻る
- 破壊不可能性・MTM伝達性はいずれも失われる
- 外見上は記録済みのものと区別がつかない

### 【E】拡散MTMの再結晶化
- ラプラスエンジン停止中は不可能
- ラプラスエンジン予備系の起動後に可能になる展開フック

### 【F】MTMの消費メカニズム

**「生成」と「励起」の分離**：

| 操作 | 必要なもの |
|---|---|
| MTMアロイへのMTM記録（無→静的） | 亜光速航行 ＋ ラプラスエンジン |
| 静的→動的への励起 | 閾値以上の熱エネルギーで十分（ラプラスエンジン不要） |
| 精密制御（どこでどう使うか） | ラプラスエンジン |

- 核融合炉・重力発生装置の熱が第6層の静的MTMを自動励起し、**ラプラスエンジンなしでも消費が継続**
- 「栓を閉める手段を失ったまま、タンクが空になっていく」状態
- ラプラスエンジン予備系の起動で消費の制御・最適化が可能になる

**消費経路の分類**：

| 消費の種類 | メカニズム | 副産物 |
|---|---|---|
| 能動的消費（核融合触媒・重力生成） | 閾値以上の熱で励起→重ね合わせを展開・収束 | 熱＋拡散MTM＋空MTMアロイ |
| 受動的消費（構造材MTMアロイの維持） | 結晶格子がMTM記録を維持するコスト | 微量の熱＋拡散MTM |
| 漏出（星空パネル劣化など） | 封じ込めが不完全になり自然解放 | 熱＋拡散MTM（制御なし） |

### 【G】MTMの輸送経路

- **第6層→第5層**：重力・圧力差を利用した自然流動で動的MTMが移動
- **第5層→第1層**：ピラー（MTMアロイ一体構造体）がMTM伝達性を通じて輸送・分配

## クストスとラプラスエンジンの関係（重要な整理）

```
クストス（統括AI）── 停止中
├─ ラプラスエンジン（MTM制御サブシステム）── 停止中
├─ ヒュドラ（水系管理）── 自律稼働中（劣化しながら）
├─ アトモスフィア（気象制御）── 自律稼働中（劣化しながら）
├─ ソル・コントロール・ユニット（人工太陽制御）── 自律稼働中
└─ バベル（言語統括・情報管理）── 状態不明

予備系：各システムに存在するが──
  切り替えにはクストスが必要 → 停止中
  手動切り替えには技術者が必要 → 2000年前の事故で失われた
  コールドスリープ中の技術者（35名）を起こせば対応可能
```

- クストスとラプラスエンジンは**別の存在**。クストスが統括AI、ラプラスエンジンはそのサブシステム
- 「クストス（ラプラスエンジン）」という一括表現は不正確→今後は区別して記述
