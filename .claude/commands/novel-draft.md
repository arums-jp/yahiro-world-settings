# novel-draft: 辺境拠点日誌 執筆→校正→膨らましスキル

このスキルは「辺境拠点日誌」の話を、**一次原稿→校正→会話膨らまし**の3ステップで仕上げます。

## 使い方

`/novel-draft <話数> [オプション]`

例：
- `/novel-draft 25` （第25話を3ステップで執筆）
- `/novel-draft 25-30` （第25〜30話をまとめて執筆）
- `/novel-draft 25 シリアス重め` （オプション付き）

## 3ステップの流れ

### ステップ1：一次原稿を書く

プロットに従って本文を書く。以下を必ず確認してから書く：
1. `辺境拠点日誌/設定/プロット_第1部.md` で該当話のあらすじを確認
2. 直前の話のファイルを読んで流れを確認
3. `辺境拠点日誌/設定/登場人物.md` でキャラクターの性格・口調を確認
4. `辺境拠点日誌/設定/拠点と周辺地理.md` で標塔・地形の描写に矛盾がないか確認

### ステップ2：整合性チェック

一次原稿を書いたら、以下を自己チェックする：

**設定の矛盾チェック**
- 標塔の見え方・方向・距離が設定と一致しているか（`拠点と周辺地理.md` の統一ルール参照）
- 禁止事項（ヤヒロという名称・鉄鋼製品・主人公一人での大型獣撃破）がないか
- キャラクターの口調・行動が設定と一致しているか
- 季節・時間軸が前後の話と矛盾していないか

**直前のパターン確認**
- 同じキャラクターの同じパターン（リュウの「聞かれなかったので」等）が繰り返されていないか
- 前の話で解決した問題が再度発生していないか

### ステップ3：会話を中心に膨らます

チェック済みの原稿を以下の方針で加筆・修正する：

**会話の膨らまし方針**
- 会話の前後に「その場の空気」「話す前の間」「返事の前の沈黙」を入れる
- キャラクターの動作（何かをしながら話している、視線の動き）を会話に織り込む
- 1〜2往復で終わっている会話を、もう1〜2往復引っ張ってキャラクターの個性を出す
- 笑いどころは「溜め→ボケ→ツッコミ→余韻」の4拍子を意識する

**周囲の環境・空気感**
- 会話シーンに季節感（気温・光・音・匂い）を一文織り込む
- 複数人が話している場面では、話していない人間も「何かをしている」描写を入れる
- 拠点の日常道具（薪・骨甲製の鍋・脚絆・帳簿など）を背景に使う

**キャラクターを立たせる**
- 各キャラクターの「コメディ上の役割」（`登場人物.md` 参照）を毎話1回は発揮させる
- スズが積極的に発言・動く場面を少なくとも1シーン確保する
- ガン・ミコト・リュウの三者のやり取りに場面の軽さを持たせる

## 品質基準

- **文字数**：約4,000文字（3,500〜4,500文字）
- **笑える場面**：最低1か所（D3ユーモア3点以上）
- **引き**：末尾に次話への疑問・予告・伏線を一文以上
- **標塔描写**：見え方・本数・方向が統一ルールと一致（`拠点と周辺地理.md` の「描写の統一ルール」参照）

## ステップ4：周辺ファイルの更新

執筆・校正・膨らましが完了したら、以下のファイルを更新すること。

### 文字数管理の更新

`辺境拠点日誌/設定/文字数管理.md` に新しい話の文字数を追記する。

**文字数の計測方法**（Pythonスクリプト）：
```python
import re
text = open(path, encoding='utf-8').read()
lines = [l for l in text.splitlines() if l and not l.startswith('#') and not l.startswith('---') and not l.startswith('*文字数')]
body = '\n'.join(lines)
count = len(re.sub(r'\n', '', body))
```

追記する列：話数・タイトル・文字数・目標比（4,000字=100%）・章合計・全体合計

### 登場人物情報の更新

執筆した話でキャラクターに以下の変化があった場合、`辺境拠点日誌/設定/登場人物.md` を更新する：
- 新しいキャラクターが登場した
- キャラクターが退場した（理由・去り際の言葉・残したもの）
- 関係性に大きな変化があった（初めて〇〇した、初めて〇〇と言った等）
- 口癖・行動パターンの新しい例が確立した
- 「第X話時点での状態」を更新すべき変化があった

### 評価レポートの更新

章単位（複数話をまとめて執筆した場合）または大きな節目（部の完成等）で、`辺境拠点日誌/評価レポート_第1部.md` を更新する。

更新内容：
1. 新しい話の個別評価レポートを追加（採点表・良かった点・改善のヒント・読者の一言）
2. 総合評価サマリーの各話スコア一覧に行を追加
3. 平均スコアを再計算
4. 「シリーズ全体の傾向」（強み・改善余地・推奨アクション）を更新
