# novel-setting: 辺境拠点日誌 設定生成スキル

このスキルは「辺境拠点日誌」用の新規設定を生成します。

## 使い方

`/novel-setting <生成したい設定の種類や要件>`

例：
- `/novel-setting 新しい獣の種類を考えてほしい。罠が効きにくい知性的な獣`
- `/novel-setting 拠点の周辺地理を詳しく設定してほしい`
- `/novel-setting 新登場人物：隊商の隊長を設定してほしい`

## 生成時の方針

設定を生成する際は以下を守ること：

1. **ヤヒロ世界の文脈に合わせる**
   - 技術水準：中世〜近世相当（銅・青銅中心、鉄はほぼなし）
   - 素材：骨甲・木材・植物繊維が主流
   - 動植物：DNA設計由来の急速進化種（通常より大型・特殊な能力を持つ場合がある）
   - 住民は宇宙船に乗っていることを知らない

2. **作品のトーン**
   - ライトノベル（ギャグ込み）
   - 主人公無双・ハーレム展開なし
   - 地道な積み重ねで信頼・影響力を拡大していく物語

3. **設定の具体性**
   - 名前・外見・特徴・行動パターンを明記
   - 物語上の使い道（コメディ要素・シリアス要素）も記載
   - 既存設定との接続ポイントを示す

4. **整合性チェック**
   - 生成後に `設定ドキュメント/` との矛盾がないか自己チェックし、問題があれば注記する

## 出力フォーマット

```markdown
## [設定名]

### 基本情報
（名前・種別・概要）

### 詳細
（特徴・能力・外見など）

### 物語での使い道
- コメディ要素：
- シリアス要素：
- 登場推奨話数：

### 整合性メモ
（既存設定との関係・注意点）
```
